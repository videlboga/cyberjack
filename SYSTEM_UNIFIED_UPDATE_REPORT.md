# Отчет об обновлении system-unified.json

## 📋 **Проблема**

**Prod и dev версии отображали старые активы и атрибуты** вместо новых, которые были добавлены в `system-definitions.json`.

### **Причина проблемы:**
- **Prod и dev используют новую систему** `loadUnifiedConfigWithAdapter()` 
- **Новая система загружает** `system-unified.json` (без новых атрибутов)
- **Старая система загружает** `system-definitions.json` (с новыми атрибутами)
- **Несоответствие данных** между двумя файлами

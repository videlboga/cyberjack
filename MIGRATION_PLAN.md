# 🚀 План миграции с JSON конфигов на базу данных

## 📋 Обзор

Этот план описывает пошаговую миграцию проекта CyberJack с файловой системы конфигов на реляционную базу данных PostgreSQL. Миграция будет проводиться аккуратно с сохранением обратной совместимости.

## 🎯 Цели миграции

1. **Устранение множественных источников истины** - единая БД вместо JSON файлов + localStorage
2. **Улучшение производительности** - индексы, оптимизированные запросы
3. **Упрощение архитектуры** - убрать адаптеры и дублирование
4. **Масштабируемость** - легкое добавление новых типов данных
5. **Консистентность** - ACID транзакции, валидация на уровне БД

## 📊 Текущее состояние

### Проблемы:
- ❌ Множественные загрузчики конфигов
- ❌ Адаптеры для совместимости
- ❌ Дублирование типов данных
- ❌ localStorage перезаписывает файлы
- ❌ Нет индексации и оптимизации
- ❌ Сложно добавлять новые типы данных

### Файлы для миграции:
- `data/characters-unified.json` → таблица `characters` + связанные
- `data/actions-unified.json` → таблица `actions`
- `data/contracts-unified.json` → таблица `contracts`
- `data/events-unified.json` → таблица `events`
- `data/equipment-unified.json` → таблица `equipment`
- `data/users-unified.json` → таблица `users`
- `data/story-scenes-unified.json` → таблица `story_scenes`
- `data/station-entities.json` → таблица `station_entities`
- `lib/character/character-ai-config.ts` → таблица `character_ai_config`

## 🔧 Технические детали

### Выбор технологий:
- **База данных**: PostgreSQL (надежность, JSONB поддержка)
- **ORM**: Prisma (типобезопасность, миграции)
- **Кэширование**: Redis (производительность)
- **Миграции**: Prisma Migrate (автоматизация)

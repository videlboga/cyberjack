# Пересборка профилей персонажей: транзактно-аналитические модели и сценарии жизни

> **Цель:** Заменить тестовые/несогласованные профили персонажей на глубокие ТА-модели (эго-состояния, жизненные позиции, драйверы, сценарии жизни, рэкет-чувства, Игры по Берну), логичные параметры и связи только с реальными организациями мира. Убрать внешних **сценарных** персонажей, сохранив личную историю (семью, прошлое) — она обосновывает сценарий жизни.

**Архитектура:** Профили живут в двух местах — авторские `characters.authoredProfiles.ts` (личность/биография/речь) + `generatedCandidates.ts` (параметры/`coreModifiers`). ТА-поля (`defaultEgoState`, `lifePosition`, `stressNeeds`, `conversationHooks`) читаются движком. Сценарий жизни (по Берну) выражается через эти поля + параметры + личную историю в профиле.

**Технологии:** TypeScript, JSON-профили, движок транзактного анализа (существующий).

---

## Принцип: личная история → сценарий жизни → ТА-модель → параметры

Каждый профиль строится цепочкой:
1. **Личная история** (биография + formative events) — что пережил, что решил про себя и мир.
2. **Сценарные решения** (по Берну) — «Я не ОК», «Не доверяй», «Радуй меня» и т.д.
3. **ТА-поля** — эго, позиция, драйверы, рэкет, Игра, сценарий-финал, антисценарий.
4. **Параметры** — выведены из психологии.

**Внешние сценарные персонажи** (Лена, Грегор, Денис, Родин, Лев, Вера, «Сигма», Вектор, няня Айра, Элара, «Проводник», куратор) — **убираются**. Семья и организации — **остаются** (они часть личной истории).

## 1. Суми (NPC-CAND-SUMI)

### Личная история
Родилась в корпоративной семье внутреннего кольца (Lattice). Отец — администратор Lattice, мать — декоративная роль. Детство — приватные образовательные блоки (протокол, языки, менеджмент, танцы, правила подачи себя). Забота выражалась ресурсами, а не эмоциями.

**Formative events:**
- В 16 узнала, что родители планируют корпоративный брак без её участия. Восприняла как оскорбление — «мне не доверяют выбор».
- В 17 ушла из дома, взяв терминал, сбережения и биометрический токен отца. Первые недели в нейтральном секторе — шок, деньги закончились быстро.
- Подписала контракт «ассистент лаборатории», не прочитав мелкий шрифт. Слово «лаборатория» ассоциировала с исследовательским центром, а не с местом, где тело — объект.

### ТА-сценарий
| Аспект | Значение | Обоснование (из истории) |
|---|---|---|
| **Сценарные решения** | «Я не ОК» (недостойна выбора), «Не будь ребёнком» (детские желания = слабость), «Радуй меня» (одобрение = забота) | родители ценили её только как функцию; протест через уход |
| **Скриптовое эго** | `free_child` (базово живая) | но под давлением → adapted_child |
| **Жизненная позиция** | `not_ok_ok` | «я недостойна, ты одобряешь» |
| **Потребности** | `approval`, `connection` | ищет одобрение и недополученную близость |
| **Драйверы** | «Будь совершенной», «Торопись» | заслуживает внимание идеальностью |
| **Рэкет-чувство** | обида / жалость к себе | «меня не ценят» → sad |
| **Игра** | `kick_me` / `if_it_werent_for_you` | жертва, подтверждающая «меня бросают» |
| **Сценарий-финал** | «меня в итоге бросят» | самосбывающееся пророчество (как с семьёй) |
| **Антисценарий** | осознать: одобрение не нужно заслуживать, выбор реален | точка роста |
| **Связи** | Lattice (семья), Veil Biotech, Helix Dynamics | корпоративное происхождение |

**Параметры:** sensitivity 55 (+5), capacity 60 (+10), openness 25 (−25), plasticity 35 (−15), attitude 30 (−20).

## 2. Ника (NPC-CAND-01)

### Личная история
Родилась в нижнем секторе города-улья, семья работников коммунального обслуживания. Усвоила: стабильность — роскошь, полагаться можно только на себя. Родители работали посменно, Ника рано стала самостоятельной.

**Formative events:**
- Отделение клиники, где работала санитарным оператором, закрыли без предупреждения. Осталась без контракта и жилья.
- Заметила нестандартные маркировки оборудования, но молчала, не желая рисковать контрактом.
- Случайно увидела, как сотрудники загружают партию стимуляторов Veil Biotech, не фигурирующую в документах. Стала свидетелем незаконной операции. Статус изменили на актив — наблюдение, контракт привязан к особым условиям.

### ТА-сценарий
| Аспект | Значение | Обоснование |
|---|---|---|
| **Сценарные решения** | «Не доверяй» (люди используют), «Будь сильной» (просить = слабость), «Не будь ребёнком» | выживание в нижнем секторе; система предала |
| **Скриптовое эго** | `adapted_child` (осторожная, подстраивается) | копит, но не показывает |
| **Жизненная позиция** | `ok_not_ok` | «я справлюсь сама, другим нельзя верить» |
| **Потребности** | `safety`, `autonomy` | безопасность + контроль |
| **Драйверы** | «Будь сильной», «Не доверяй» | не просит помощи, взвешивает |
| **Рэкет-чувство** | праведный гнев / недоверие | «меня хотят использовать» → angry |
| **Игра** | `nigsyb` / `rapo` | контролёр, наказывает подведших |
| **Сценарий-финал** | «останусь одна, но выживу» | одиночество как защита |
| **Антисценарий** | позволить довериться и просить помощи | точка роста |
| **Связи** | Veil Biotech (бывший работодатель), клинический сектор | |

**Параметры:** sensitivity 48 (−2), capacity 64 (+14), openness 38 (−12), plasticity 52 (+2), attitude 45 (−5).

## 3. Мира (S-AV-01)

### Личная история
Родилась в бедных внешних кольцах, семья на грани выживания. Отец — рабочий завода, мать — уборщица. В 14 родители погибли при «аварии» на заводе; Мира подозревает, что это связано с документами отца (упоминание Lattice). Её передали в корпоративную систему активов. Процедурный профиль выявил высокую толерантность к боли — попала в программу искателей Аномалии. Два года ритуалов (шрам на скуле, боль как «канал истины»). После бунта группы программу свернули, Миру перевели обычным активом в лабораторию.

### ТА-сценарий
| Аспект | Значение | Обоснование |
|---|---|---|
| **Сценарные решения** | «Не живи» (семья уничтожена, я виновата), «Стремись» (искупление через страдание), «Не будь ребёнком» | гибель семьи, ритуалы боли |
| **Скриптовое эго** | `adapted_child` (покорная, подчиняется) | но ищет правду |
| **Жизненная позиция** | `not_ok_ok` | «я виновата, ты решаешь» |
| **Потребности** | `safety`, `approval` | защита + одобрение |
| **Драйверы** | «Стремись», «Радуй» | старается быть «хорошей», чтобы не наказали |
| **Рэкет-чувство** | безнадёжность / страдание | «меня всегда бьют» → distressed |
| **Игра** | `wooden_leg` / `kick_me` | жертва, использующая страдание |
| **Сценарий-финал** | «не выберусь, умру как расходник» | фатализм |
| **Антисценарий** | правда освобождает, а не наказывает | точка роста |
| **Связи** | Lattice, Культ искателей, Корпорация (система активов) | |

**Параметры:** sensitivity 60 (+10), capacity 50 (0), openness 100 (+50), plasticity 100 (+50), attitude 100 (+50). *Высокая пластичность/открытость — выжила в культе, адаптивна; высокая attitude — внутренняя опора на правду.*

## 4. Иона (NPC-LAB-01)

### Личная история
Родилась в клиническом секторе у внешней обшивки. Отец — инженер, мать — медсестра. С детства усвоила: показания приборов — это жизни. Стала оператором медицинской телеметрии.

**Formative events:**
- В аварийную смену заметила нестабильный кардиоритм, трижды предупредила, но врач и медсестра отмахнулись. Пациент умер от тромбоэмболии. Руководство переписало журнал.
- Скопировала оригинальную телеметрию. Подала рапорт о «неисправности логирования» — расследование замяли, перевели подальше от пациентов.
- В архивах нашла серию аномальных паттернов (скрытый протокол). Кто-то пытался вскрыть её сейф.

### ТА-сценарий
| Аспект | Значение | Обоснование |
|---|---|---|
| **Сценарные решения** | «Будь совершенной» (ошибка = вина), «Не будь собой» (эмоции = слабость), «Не чувствуй» | смерть пациента, переписанный журнал |
| **Скриптовое эго** | `nurturing_parent` (заботится, контролирует) | подавляет эмоции за профессионализмом |
| **Жизненная позиция** | `ok_ok` (компетентна) | но не доверяет чужим решениям |
| **Потребности** | `clarity`, `connection` | ясность + подавленная близость |
| **Драйверы** | «Будь совершенной», «Спеши» | точность как защита от вины |
| **Рэкет-чувство** | вина / тревога | «я должна была предотвратить» |
| **Игра** | `why_dont_you_yes_but` / `i_am_only_trying_to_help` | «я знаю лучше», отвергает помощь |
| **Сценарий-финал** | «несу ответственность за всех» | выгорание от гиперответственности |
| **Антисценарий** | ошибка не делает её виноватой | точка роста |
| **Связи** | Veil Biotech, клинический сектор | расследование протокола |

**Параметры:** sensitivity 50 (0), capacity 68 (+18), openness 42 (−8), plasticity 45 (−5), attitude 58 (+8).

## 5. Эли (NPC-CAND-GEN-02)

| **Скриптовое эго** | `adapted_child` (дисциплинированная, подавляет) | |

| **Потребности** | `approval`, `clarity` | искупление через признание |

**Formative events:**
- В 7 отдала половину обеда незнакомому плачущему мальчику, хотя сама была голодна.
- В 12 полюбила сортировать данные — упорядочивание успокаивает.
- В 18 куратор сказал «вернусь через пять минут» и не вернулся. Просидела 4 часа в пустой комнате. Куратор был связан с Lattice.

|---|---|---|

## Реализация

### Файлы для изменения
- `src/scenario/characters/authoredProfiles.ts` — заменить JSON-загрузку на компактные профили в коде (или переписать JSON без внешних сценарных персонажей).
- `src/scenario/eventLibrary/*_authored_profile.json` — пересобрать: убрать внешних сценарных персонажей из `relationships` и `relatedPeopleAndGroups`, оставить семью и организации.
- `src/scenario/generatedCandidates.ts` — задать явные `coreModifiers` вместо LLM-генерации.
- `src/scenario/characterStorySeeds.ts` — убрать внешние ссылки, оставить организации.
- `src/scenario/worldService.ts` — параметры Ники/Ионы/Миры (если закреплены).

### Социальные ТА-поля
```json
"social": {
  "defaultEgoState": "...",
  "lifePosition": "...",
  "stressNeeds": ["..."],
  "conversationHooks": ["..."]
}
```

### Верификация
- `npx tsc --noEmit` — чисто.
- `npx vitest run` — 620+ тестов зелёные.
- Параметры соответствуют таблицам.
- В профилях нет внешних сценарных персонажей (grep по именам).
- Личная история каждого сохранена.

## Риски / открытые вопросы

1. **Авторские JSON огромны** (60-90KB) — переписывать вручную или заменить на компактные профили в коде? (Рекомендую компактные в коде, т.к. `compileAuthoredProfile` читает лишь подмножество полей.)
2. **Параметры кандидатов** — сейчас генерируются LLM; нужен override в `CandidateSeed`.
3. **Сценарий жизни** — пока не читается кодом напрямую; выражается через 4 ТА-поля + личную историю (LLM-память). Если нужно, чтобы движок реально использовал его — расширение `socialTransactions.ts`.
4. **Мира** — высокая пластичность/открытость (100) из-за культового прошлого; проверить влияние на динамику эго.

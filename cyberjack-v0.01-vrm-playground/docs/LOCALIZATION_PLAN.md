# План локализации Cyberjack UI (перевод всего контента под новые языки)

> **Статус:** в работе. Фундамент и БД-контент готовы; основной UI-хардкод
> (экранные подписи, панели, дроверы) ещё переводится.
> **Ветка:** `agent/legacy-audit`
> **Обязательное условие:** промты (LLM-промпты, `src/prompts/*`) **НЕ трогать**;
> генеративные элементы (нарративы, воспоминания, реплики персонажей) переводятся
> отдельно и в этот план не входят.

## 1. Принцип локализации (уже внедрён)

Паттерн: **БД остаётся источником ID**, а отображаемые строки живут в
locale-файлах. Новые языки добавляются **только** в `locales/*.json`, код не меняется.

- Источник переводимых текстов — `locales/ru.json` и `locales/en.json`.
- Доступ из компонента: `const { t } = useI18n();` → `t('game.ui.someKey')`.
- Для контента из БД (действия, точки, предметы, черты, ассеты, комнаты, офферы)
  есть центральный слой `src/ui/contentTranslations.ts` с функциями:
  `translateActionLabel`, `translatePointLabel`, `translateItem`, `translateTrait`,
  `translateAsset`, `translateRoom`, `translateOffer`. Они принимают `id` и `t`,
  возвращают переведённую строку или исходный ID (fallback).

### Уже переведено (НЕ переделывать)
- **Меню** — глобальный `GameMenu.tsx` (выбор языка RU/EN) доступен на всех экранах
  через кнопку «≡ Меню» в статусбаре. `LanguageSelector.tsx` удалён.
- **БД-контент** — `game.content.*` в обоих locale-файлах заполнен:
  - 130 `action_presets.label`
  - 29 `point_presets.label`
  - 27 `items.name/description`
  - 10 `traits.name`
  - 4 `laboratory_assets`, 4 `laboratory_rooms`, 23 `shop_offers` (name/description)
- **Интеграция в CampaignApp**: инвентарь → `translateItem`; офферы снабжения →
  `translateOffer` + `translateAsset`; комнаты/ассеты уже через `getRoomName`/
  `getDeviceName`/`getRoomDescription` (`src/ui/roomTranslations.ts`).
- Проверено: EN-переводы не содержат утечек кириллицы, JSON валиден, `tsc` чист,
  574 теста зелёные.

## 3. Конвенции и подводные камни

1. **Регулярные выражения по русским словам.** Много мест проверяют текст по
   кириллице: `CapsuleHistoryChart` (оргазм/срыв/поза), `CampaignApp` строка 2798
   (`replace(/^Надеть\s+/)`), строка 4573 (`/помещ[её]н.*устройств|капсул/`).
   В EN-режиме такие проверки сломаются. Их надо переделать на **ID/ключи**, а не
   на строки, либо проверять уже локализованные значения по обоим языкам.
2. **`calibrationActions` label/hint** — предпочесть `translateActionLabel(id, t)`,
   чтобы не дублировать перевод. `hint` пока не имеет ключа — добавить
   `game.content.actions.<id>.hint`.
3. **Плюрализация.** Ключи вида «6 персонажа», «12 на складе», «4 оборуд.» —
   уже есть как `game.ui.residents`, `inStock`, `equipment`, но склонение
   («персонажа»/«персонажей») хардкодное. Для нового языка нужен правильный
   plural (можно через `Intl.PluralRules` или набор форм в locale).
4. **Стиль заголовков.** UI использует заглавные подписи («РИТМ», «ПРЕДЕЛ»,
   «МЕНТАЛЬНАЯ КОРРЕКЦИЯ»). В EN сохранять верхний регистр в ключах.
5. **Не трогать промты и генеративку.** `src/prompts/*`, реплики персонажей,
   воспоминания, нарративы — вне этого плана.
6. **Проверка после правок:** `npx tsc --noEmit` → 0 ошибок; `npx vitest run` →
   574 passed; вручную переключить язык RU→EN в меню и убедиться, что экраны
   (досье, секс-машина, калибровка, снабжение, склад) отображаются по-английски
   без «протечек» русских строк.
7. **Не ломать fallback.** Все `translate*` возвращают исходную строку/ID, если
   ключа нет. Так безопасно добавлять переводы по частям.

## 4. Рекомендуемый порядок работы

1. **CampaignApp.tsx** — досье персонажа (самый заметный игровой экран).
2. **CampaignApp.tsx** — панель секс-машины + капсула/камера.
3. **CalibrationPrototype.tsx** — карта тела + монитор состояния + клавиши A/D/E.
4. **CalibrationPrototype.tsx** — протокол/очередь/цели + ревью аватара.
5. **CalibrationPrototype.tsx** — `calibrationActions.label/hint` через
   `translateActionLabel` + `game.content.actions.<id>.hint`.
6. **CapsuleHistoryChart.tsx** — перевод + переделка regex на ID.
7. Средний/низкий приоритет: CharacterChat, GameVisualEffects, ConfigEditor,
   концепты, dev-экраны.

Для каждого экрана: (а) вынести строки в `t('...')`, (б) добавить ключ в `ru.json`
(оригинал) и `en.json` (перевод), (в) проверить `tsc` + визуально.

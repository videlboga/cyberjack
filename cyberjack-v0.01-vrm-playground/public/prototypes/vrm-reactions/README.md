# Cyberjack — прототип живой сцены

Отдельная демонстрация. Не отправляет игровые действия в API и не изменяет состояние персонажей в основной игре.

Из корня cyberjack-v0.01:

```sh
python3 -m http.server 8779 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8779/public/prototypes/vrm-reactions/

Основное приложение отдельно: `npm run dev`; API: `PORT=3001 ./node_modules/.bin/tsx src/api/server.ts` (порт соответствует proxy Vite).

## Что демонстрируется

- VRM Рин в исходном костюме 00, текстуры и физика; фиксированный шаг пружин 1/60.
- Исходные Koikatsu клипы Idle_00_00, Stand_00_00, Stand_Joy_01, Stand_03_00, Stand_01_00; переходы 450 мс.
- Глаза, брови, рот через сохранённые таблицы лицевых морфов; автоморгание и небольшой процедурный кивок.
- Четыре нейтральных действия, очередь до трёх следующих реакций, отмена и возврат к idle.
- Субтитры, история диалога, общий/приближённый план, адаптация под телефон.
- Опциональная Web Speech API озвучка. Реплики фиксированы. Рот двигается приблизительно по времени речи; фонемного lip sync и интеграции TTS игры нет. Голос может отсутствовать в браузере.
- «Меньше движений» оставляет базовый idle и мимику, отключает смену поз/процедурные жесты и плавное движение камеры; учитывается prefers-reduced-motion.

## Файлы и ограничения

`index.html`, `manga2.css`, `prototype.js` — весь UI и постановка реакций. Текущая версия повторяет расположение блоков рабочей сессии Manga 2: персонаж слева, мониторы по центру, чат справа, иллюстрированная палитра снизу. Карточки используют портреты из `public/character-images/portraits/rin/`; числовые показатели мониторов статичны и отмечены как пример. `conversation-v1.html` + `prototype.css` — первоначальный упрощённый вариант. `vendor/` — локальные копии Three.js, GLTFLoader, OrbitControls, three-vrm и лицевого контроллера рабочего вьювера. `assets/` — копии банка поз, карты костей и лицевого каталога. `assets/Rin.vrm` — относительная ссылка на `character-work/x20/outfits/Rin_outfit_00.vrm` внутри этого проекта, чтобы не дублировать 72 МБ модели. Для переноса на другой хост скопировать целевой VRM вместо ссылки. Лицензии библиотек сохранены в исходных модулях; права на исходные модель/анимации определяются их владельцами.

Слой реакций пока использует локальные демонстрационные события. Следующий этап — адаптер подтверждённых игровых событий в intent (actor, action, mood, clip, face, speech) с отдельным владельцем каждого слоя. В исходную сцену игры прототип не встроен.

# Проба VRM-взаимодействия

Открыть http://127.0.0.1:5174/manga?focus=S-AV-01 и обновить страницу.

1. Дождаться загрузки модели. Включённый пункт «Действия на модели» означает: карточки воздействий выбирают инструмент. Имя инструмента видно рядом с моделью. Для возврата к прежним немедленным действиям карточками снять флажок.
2. Без инструмента нажать на ступни или руку: выбирается точка и камера приближает её. Можно пользоваться прежней картой точек. «Весь рост» возвращает общий план.
3. Выбрать «Мягко погладить» в карточках. Навести на модель: подпись показывает область и допустимость. Короткий клик выполняет одну команду по этой области. Перетаскивание вращает камеру и ничего не применяет. Alt+клик меняет только фокус, Esc снимает инструмент.
4. Следить за постоянной стойкой, дыханием и лицом: они используют данные состояния/телеметрии, а не только последнее действие. Нельзя отдельно редактировать их тестовые параметры в игре; контрольные инъекции есть лишь в QA.
5. Сильная реакция может включить короткий план лица с возвратом. Отключается флажком «Камера сильных реакций». У выбранной команды при этом не меняется точка.

Настройки рендера и тестовые отклики находятся в раскрывающемся блоке «Рендер и тесты» под основным управлением сцены.

Это первая версия привязки областей лёгкими капсулами вокруг костей, без дорогой проверки треугольников модели. Надёжнее всего различаются крупные области; мелкие точки не имеют отдельной 3D-разметки и остаются в прежней панели. На швах одежды смотрите подпись наведения. Для всех состояний пока используются три исходные стойки и укрупнённые паттерны мимики, а не новые специализированные клипы для каждого воздействия.

Сборка и runtime TypeScript проходят. В `validation/body-stage-interaction-qa.json` сохранён перехваченный POST к arms / gentle_stroke: при проверке он отменён, сохранённое состояние игры не менялось.

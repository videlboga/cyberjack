# 🧪 Тестовая страница механик CyberJack

## Обзор

Тестовая страница для проверки работы инструментов и действий в CyberJack с минимальным UI. Позволяет тестировать все механики в изолированной среде без влияния на основное приложение.

## Доступ

Страница доступна по адресу: `http://localhost:3000/test/mechanics`

## Функциональность

### 🎯 Основные возможности

1. **Выбор персонажа** - из загруженной конфигурации
2. **Выбор инструментов** - все доступные инструменты из конфига
3. **Выбор действий** - все доступные действия из конфига
4. **Тестирование зон** - интерактивные зоны на силуэте персонажа
5. **Мониторинг эффектов** - реальное время отслеживание изменений статов
6. **Логирование событий** - подробные логи всех действий
7. **LLM сообщения** - симуляция AI ответов

### 🎮 Режимы работы

#### Click-режим (левый клик)
- Мгновенное применение эффектов
- Срабатывание по достижении количества кликов (из `llmTrigger.clicks`)
- Эффекты рассчитываются по формуле: `baseValue * intensity/10 * multiplier`

#### Hold-режим (удержание)
- Применение эффектов каждые N секунд (из `effectRate.perSecond`)
- LLM сообщения каждые M секунд (из `llmTrigger.seconds`)
- Визуальная индикация активной зоны
- Автоматическая остановка при отпускании/уходе с зоны

### 📊 Отслеживаемые метрики

- **Статистика персонажа** - изменения статов в реальном времени
- **Количество таймеров** - активные интервалы
- **Время работы** - секундомер с момента загрузки
- **Активные зоны** - зоны с запущенными hold-циклами

## Использование

### Базовый сценарий тестирования

1. **Выберите персонажа** из списка
2. **Выберите инструмент** и настройте интенсивность
3. **Кликните по зоне** для тестирования click-режима
4. **Удерживайте на зоне** для тестирования hold-режима
5. **Следите за эффектами** в панели статистики
6. **Проверяйте логи** для понимания происходящего

### Расширенное тестирование

- **Тестируйте комбинации** инструментов и действий одновременно
- **Проверяйте LLM триггеры** в соответствующих панелях
- **Мониторьте производительность** по количеству активных таймеров
- **Тестируйте edge cases** - быстрые переключения, множественные зоны

## Отладочная информация

### Логи
- Все действия логируются с timestamp
- Эффекты отображаются с точностью до сотых
- LLM сообщения выделены специальным стилем

### Визуальная обратная связь
- **Активные зоны** - зеленая анимация + "HOLD" индикатор
- **Эффекты** - цветовое кодирование (зеленый/красный)
- **Таймеры** - счетчик активных интервалов

## Troubleshooting

### Таймеры не запускаются
- Проверьте, что инструмент/действие поддерживает hold-режим (`modes` содержит `"hold"`)
- Убедитесь, что выбрана интенсивность > 0

### Эффекты не применяются
- Проверьте конфигурацию инструмента/действия
- Убедитесь, что персонаж выбран
- Проверьте логи на наличие ошибок

### LLM сообщения не появляются
- Проверьте настройку `llmTrigger` в конфигурации
- Для click-режима: дождитесь нужного количества кликов
- Для hold-режима: удерживайте зону нужное количество секунд

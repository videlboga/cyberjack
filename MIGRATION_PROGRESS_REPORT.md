## 🚀 Что работает

### API Endpoints:
- **GET** `/api/db/health` - статус БД и статистика
- **GET** `/api/db/config` - полная конфигурация игры
- **GET** `/api/db/characters` - список всех персонажей
- **POST** `/api/db/characters` - создание персонажа
- **PUT** `/api/db/characters` - обновление персонажа
- **DELETE** `/api/db/characters` - удаление персонажа

### База данных:
- **17 таблиц** созданы и готовы к использованию
- **Индексы** настроены для оптимизации
- **Триггеры** для автоматического обновления timestamps

## 🔧 Технические детали

### Docker контейнер:
```bash
docker run --name cyberjack_postgres \
  -e POSTGRES_USER=cyberjack \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=cyberjack \
  -p 5433:5432 \
  -d postgres:15-alpine
```

### Подключение:
- **Хост**: localhost
- **Порт**: 5433
- **База**: cyberjack

# 🎯 Руководство по интегрированной системе условий

## 📍 Где найти систему условий

### 1. В редакторе сюжетов
Перейдите в **`/game/story-editor`** и выберите вкладку **"Точки"** (StoryPoints).

### 2. В верхней панели
Нажмите на кнопку **"Условия"** в панели инструментов.

### 3. Создание нового условия
Нажмите кнопку **"Добавить условие"** в правом верхнем углу.

## 🎮 Как использовать систему условий

### Шаг 1: Создание условия
1. Нажмите **"Добавить условие"**
2. В правой панели появится **ConditionBuilder**
3. Выберите тип условия:
   - **Условие на актив** - проверка атрибутов персонажей
   - **Условие на игрока** - проверка состояния игрока
   - **Условие на выбор в сцене** - проверка выборов в сценах
   - **Условие на сюжетную точку** - проверка значений сюжетных точек

### Шаг 2: Настройка условия
В зависимости от выбранного типа:

#### Для условий на активы:
- **Актив**: Выберите "Любой актив", "Текущий актив", "Принадлежащий актив" или конкретный актив
- **Атрибут**: Выберите из категорий:
  - Основные атрибуты (сила, интеллект, эмпатия и т.д.)
  - Навыки (обслуживание, кулинария, нейрохакерство и т.д.)
  - Состояние (здоровье, психическое состояние, стресс)
  - Метаданные (ранг, цена, статус)
  - Трейты и предпочтения
- **Оператор**: Выберите подходящий оператор (равно, больше, содержит и т.д.)
- **Значение**: Введите требуемое значение

#### Для условий на игрока:
- **Атрибут**: Выберите из категорий:
  - Аккаунт (баланс, валюта)
  - Активы (количество активов)
  - Оборудование (количество оборудования)
  - Настройки (толерантность к риску, уведомления)
- **Оператор** и **Значение**: Настройте как для активов

### Шаг 3: Тестирование условия
1. Нажмите кнопку **"🧮 Вычислить условие"**
2. Увидите результат: **✅ Истинно** или **❌ Ложно**
3. Условие автоматически валидируется и показывает статус

## 📊 Примеры использования

### Пример 1: Условие доступа к элитным активам
```
Тип: Условие на игрока
Атрибут: Баланс
Оператор: >=
Значение: 1000
```
**Результат**: Игрок с балансом >= 1000 может получить доступ к элитным активам

### Пример 2: Условие для технических заданий
```
Тип: Условие на актив
Актив: Любой актив
Атрибут: Нейрохакерство
Оператор: >=
Значение: 3
```
**Результат**: Актив с навыком нейрохакерства >= 3 может выполнять технические задания

### Пример 3: Условие для лояльных активов
```
Тип: Условие на актив
Актив: Любой актив
Атрибут: Трейты
Оператор: содержит
Значение: loyal
```
**Результат**: Актив с трейтом "loyal" может выполнять особые задания

### Пример 4: Условие для опытных активов
```
Тип: Условие на актив
Актив: Любой актив
Атрибут: Задания
Оператор: >=
Значение: 10
```
**Результат**: Актив с 10+ выполненными заданиями считается опытным

## 🔧 Возможности системы

### ✅ Что уже работает:
- Создание условий на активы и игроков
- Автоматическая валидация условий
- Вычисление условий в реальном времени
- Интуитивный интерфейс с подсказками
- Поддержка всех типов атрибутов
- Группировка атрибутов по категориям

### 🔮 Что можно добавить:
- Составные условия (AND/OR)
- Условия на сцены и сюжетные точки
- Сохранение условий в проекте
- Экспорт/импорт условий
- Шаблоны часто используемых условий

## 🚀 Интеграция с игрой

Система условий интегрирована в:
- **StoryPointsManager** - для триггеров сюжетных событий
- **StoryEditor** - для создания сложной игровой логики
- **Существующие системы** - легко подключается к любой части игры

## 📝 Советы по использованию

1. **Начните с простых условий** - проверьте базовую функциональность
2. **Используйте валидацию** - система покажет ошибки в настройке
3. **Тестируйте условия** - кнопка "Вычислить условие" покажет результат
4. **Комбинируйте атрибуты** - создавайте сложную логику
5. **Используйте описания** - добавляйте понятные названия и описания

# План пересборки UI для Калибратора Активов

## 🎯 Цель
Пересобрать UI режима "Личная работа" под концепцию NSFW игры с БДСМ элементами, убрав нейтральные элементы и добавив функциональность для работы с активами.

## 🔄 Что убираем

### 1. Несколько режимов личной работы
- Оставляем только один режим - "Калибратор Активов"
- Убираем переключения между режимами

### 2. Нейтральные элементы
- Убираем "маркер", "планшет", "AR-дисплей"
- Убираем нейтральные области взаимодействия
- Убираем профессиональные инструменты

## 🆕 Что добавляем

### 1. Система оборудования (Equipment System)
**Функции:**
- Перемещение между комнатами
- Переодевание активов
- Использование БДСМ устройств
- Настройка параметров устройств

**Категории оборудования:**
- **Ограничители**: наручники, ошейники, цепи, кандалы
- **Устройства стимуляции**: вибраторы, электростимуляторы, температурные устройства
- **Одежда**: униформа, БДСМ костюмы, декоративные элементы
- **Мебель**: столы, стойки, кресты, кресла
- **Инструменты**: плети, хлысты, щетки, массажеры

### 2. Интерактивные действия (Action System)
**Палитра действий:**
- **Физические воздействия**: ударить, погладить, щекотать, массажировать
- **Стимуляция**: вибрация, электричество, холод, тепло
- **Ограничения**: связать, зафиксировать, освободить
- **Психологические**: угрожать, хвалить, унижать, подчинять

**Инструменты:**
- **Рука**: базовые воздействия
- **Плеть/Хлыст**: болевые воздействия
- **Вибратор**: стимуляция
- **Электростимулятор**: электрические воздействия
- **Термоустройство**: температурные воздействия
- **Щетка**: щекотка и массаж

### 3. Быстрые действия (Quick Actions)
**Смена поз:**
- Список доступных поз
- Проверка характеристик для добровольной смены
- Принудительная смена через LLM

**Другие быстрые действия:**
- Заставить говорить
- Изменить одежду
- Переместить в другую комнату
- Активировать устройство

### 4. Улучшенная LLM система
**Базовый промпт:**
```
Ты ${character.name}, подопытный актив на космической станции
```

**Конструктор промптов:**
- Характеристики с интерпретацией
- Сообщение пользователя
- Контекст сообщений
- Система памяти
- Информация о происходящем

**Параллельный анализ через Gemini:**
- Анализ сообщения на угрозы/нежность/насмешки
- JSON ответ с изменениями характеристик
- Приказы сменить позу с проверкой характеристик

# Cyberjack · библиотека модульных машин v1

Небольшой набор параметрических Blender-модулей и четыре сборки под существующие
ID оборудования движка. Все размеры в метрах. Это **визуально-механический
концепт-кит**, а не сертифицированная конструкция или доказательство безопасности.

## 1. Источники

Использована только сама 3D-геометрия из `public/models`:

- vol-03: `prepared-2026-10-16/models/*.glb`, 065–088;
- vol-04: исходные `*.skp`, 089–100, импорт напрямую через OpenSKP.

Всего рассмотрено 36 моделей, по два свежих ракурса каждой. Общие авторские
прелоадеры и изображения вне `public/models` не использовались как референсы.

Конструктивные источники: открытые порталы 078/095, рельсы 084/098, колонны и
выносы 079/080, регулируемые опоры 073/087, компактные рабочие узлы 089/090,
ротационная форма 065/096. Глухие корпуса, скрывающие механизм, не копируются.

## 2. Function Contract

Общий путь: **загрузка на опоры → настройка положения → работа сменного узла →
стоп → доступ для снятия и обслуживания**.

- **M-01 / vaginal:** портал + вертикальная и горизонтальная настройка + линейный узел.
- **M-02 / anal:** низкий открытый линейный узел на двух опорных стойках.
- **M-03 / tickling:** две щёточные головки на общей регулируемой раме.
- **M-04 / circularsaw:** мягкий ротационный контур; никаких металлических зубьев.

Загрузка и обслуживание предполагаются только в остановленном состоянии.
Защита, блокировки и аварийная логика требуют отдельной инженерной проработки.

## 3. Карта модулей

| ID | Класс | Назначение | Движение / предел |
|---|---|---|---|
| `structure_base` | STRUCTURE | Четыре опоры и общая станина | неподвижна, контакт z=0 |
| `structure_portal` | STRUCTURE | Открытая двухстоечная рама | неподвижна |
| `motion_linear` | MOTION | Двухрельсовая каретка с упорами | X ±0.22 м |
| `motion_lift` | MOTION | Вертикальная регулировка | Z ±0.12 м |
| `work_probe` | WORK | Сменный линейный контактный узел | номинальный визуальный ход Y 0.12 м |
| `work_rotary` | WORK | Мягкий контур и открытая рамка ограждения | вращение вокруг Y |
| `work_brush_pair` | WORK | Две щёточные головки | два ротора вокруг Y |
| `support_cradle` | SERVICE | Две опоры с мягкими ложементами | монтажная высота 0.48–0.96 м |
| `interface_console` | INTERFACE | Экран, состояние, физический стоп | неподвижен, сторона оператора −Y |
| `utility_routing` | UTILITY | Пульт–станина–привод | фиксированный сервисный контур |

Каждый модуль в `catalog.json` содержит `purpose`, `connects_to`, `limits`,
`access`, `visible_evidence`, `material_role`, `status` и `source_models`.

## 4. Дизайн-код

- Основа: молочный `#F1EFEA`, вторичные панели `#FAF8F4`.
- Рабочие узлы: пудровый розовый `#E8B9BF`; мягкий контакт `#F2D7D9`.
- Направляющие и нагруженные соединения: `#B9BAB7`, `#54575A`.
- Экраны: `#E4F4F5`; стоп: красный на жёлтом основании, не розовый.
- Матовые скруглённые корпуса; открытые направляющие; без фальшивой вентиляции,
  случайных болтов, декоративных рук и скрытия механизма в глухом боксе.

## 5. Файлы и использование

```text
public/models/machine-modules/
  machine_modules.blend          # 14 asset-marked collections
  catalog.json                   # единый машиночитаемый реестр
  modules/*.glb                  # 10 независимых модулей
  assemblies/*.glb               # 4 сборки с ID из движка
```

```python
from ink_kit import Frame
from machine_modules import build_machine, build_module

# Существующий Frame комнаты; детали получают теги machine_module/module_class.
build_machine('lab_sex_machine_tickling', room.frame(0.0, 0.5))
build_module('motion_linear', room.frame(1.5, 0.0), slide=0.0)
```

Three.js:

```ts
const gltf = await loader.loadAsync(
  '/models/machine-modules/assemblies/lab_sex_machine_circularsaw.glb'
);
scene.add(gltf.scene);
```

GLB: Y-up, метры, встроенные материалы и extras `machine_module`, `module_class`,
`asset_id`. Blender: Z-up. Допустимые стыки хранятся как точные `joint_keys` на
двух деталях, а не как исключения по префиксам.

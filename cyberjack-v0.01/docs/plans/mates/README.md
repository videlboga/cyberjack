## Что важно знать

Точки выведены из геометрии GLB, а не из шаблонов контрактов. Поэтому
паспортные стандарты местами расходятся с фактической посадкой:

- у большинства компонентов контрактный `mount_in = 4×M12 pitch 0.6`
  не подтверждён; в геометрии другие болтовые поля или лапы;
- паспортный байонет 20/25 мм подтверждён только у `work_air_jet`;
  у насадок — обоймы/фланцы/хомуты, у части — надевание;
- у 8 поверхностей нет болтовых бобышек — `mount_in` поставлен по
  центру опорной плоскости, low confidence;
- у части SENSORY/CONTROL/UTILITY контрактные порты (C20, G1/4, RJ45)
  не совпадают с фактическими разъёмами; названия даны по геометрии;
- `motion_oscillating.tool_out` — бобышка Ø28 без ISO-площадки;
- `work_electro_pad`/`work_thermal_pad` — накладки без монтажного
  байонета, точка на тыльной плоскости, low confidence.

Low-confidence точки не удалены: они помечены, чтобы каталог был честным,
а не «дорисованным».

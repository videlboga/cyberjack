# Расширение пула тем + продолжение разговоров + анти-повтор между thread'ами

> **Цель:** Устранить зацикливание проактивных диалогов (повтор «полторы секунды» и т.п.) и сделать разговоры живыми: расширить пул тем, динамически генерировать новые, продолжать незакрытые разговоры вместо «начала заново», и не повторять уже сказанные фразы между разными разговорами.

**Архитектура:** Тема выбирается в `chooseTopic` (socialTransactions.ts) из: активного thread → `conversationHooks` (профиль) → тем из памяти пары (`memoryThemesForPair`). Thread живёт в `social_threads`, закрывается через `shouldContinueConversation` (staleStreak/лимит).

---

## Текущее состояние (диагноз)

1. **Пул тем мал и статичен**: `conversationHooks` = 3-4 на персонажа. Быстро исчерпывается.
2. **Resolved-темы возвращаются**: после cooldown 30 мин тема снова доступна → модель повторяет фразы.
3. **Нет продолжения**: при `resolved` создаётся новый thread с той же темой, модель начинает с нуля.
4. **Анти-повтор только внутри thread**: staleStreak работает в одном разговоре, но не между разными.

---

## План (с учётом решений)

### 1. Расширить пул тем изначально — ШИРЕ

Увеличить `conversationHooks` до **8-12** у каждого персонажа, добавив темы из личной истории, сценария жизни и мира:

| Персонаж | Текущие | Расширить до |
|---|---|---|
| **Суми** | ступни, массаж, протокол | + семья, уход из дома, корпоративный сектор, музыка, одежда, еда, сон, одиночество |
| **Ника** | соглашения, условия, безопасность | + клиника, нижний сектор, выживание, наблюдения, работа, смена, инструменты, страх |
| **Мира** | границы, доверие, прошлое | + культ, семья, Lattice, ритуалы, боль, шрамы, вера, обещания |
| **Иона** | работа, лаборатория, наблюдения | + телеметрия, пациент, протокол, вина, клиника, данные, смена, оборудование |
| **Эли** | работа, будущее, статус | + сектор 7-В, Lattice, вина, протоколы, отец, архивы, порядок, страх |
| **Май** | наблюдения, протокол, другие | + куратор, одиночество, данные, порядок, Lattice, правила, контроль, ожидание |

### 2. Динамическое расширение пула

**Детерминированная генерация** новых тем из:
- личной истории персонажа (`biography.formativeEvents`),
- текущего состояния (что он заметил/пережил),
- сценария жизни (ТА).

**Плюс: новые темы из эпизодов памяти** — после генерации субъективных эпизодов (`subjective_memory_episodes`) их `title`/`summary` становятся темами для будущих разговоров. Это уже частично есть в `memoryThemesForPair`, но нужно усилить: брать **все** эпизоды, а не только с участием пары, и использовать их как источник новых тем.

### 3. Продолжать, а не начинать заново — СЛУЧАЙНО

Решение «продолжить незакрытый разговор vs сменить тему» — **рандомизировать**:
- Если есть незакрытый open loop — с вероятностью ~60% продолжить его, ~40% сменить тему.
- Если thread `resolved` недавно — не выбирать ту же тему подряд (трекать последнюю тему пары).

### 4. Анти-повтор контента между thread'ами

Проверять, не говорил ли персонаж уже эту фразу/тему в недавних разговорах пары. Если повторяется — сменить тему.

## Риски / открытые вопросы

1. **Объём conversationHooks** — 8-12 тем не перегрузят промпт (они используются как крючки, а не весь список).
2. **Случайное продолжение** — рандомизация 60/40 даёт разнообразие, но не хаос.
3. **Эпизоды памяти как темы** — нужно убедиться, что темы из эпизодов осмысленны и не дублируют статичные.

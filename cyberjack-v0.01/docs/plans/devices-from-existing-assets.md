## 2. Решения по ходу

1. **Капсула** — `Creature Tank`: цилиндр с прозрачной крышкой и станиной.
   Читается сразу и совпадает с ролью (вертикальная ёмкость с жидкостью).
   Единственная замена — цилиндр, а не «ложемент»: актив стоит, а не лежит.
2. **Модуль C** взят из GLB, а не из `.blend`: файл `tickle_chair_v1.blend`
   сохранён Blender 5.x (zstd), в 4.2 не открывается — импортируется только
   `converted/tickle_chair_v1.glb`. У мешей сняты армтура и модификаторы, иначе
   габарит не масштабируется.
3. **Модуль D** — большое колесо на станине из `GordProps` (там же мотор,
   I-beam, вентиляция): ротационный узел без авторской модели.
4. **Модуль B** — тележка `dildo_chair`: низкая станина 0.78 м с вертикальным
   приводом; подходит для «станка сзади».
5. **Модуль A** — сибиан-купол `BarbellSybian_V2`: закрытый купол с пультом,
   самый «фабричный» из всех.

## 3. Где набор слабый (честно)

| Проблема | Что делать |
|---|---|
| Кресло коррекции — узкая стойка 0.51 × 0.64, читается как «рама с ремнями», а не кресло | добавить сиденье и визор из `fukonaMachine` (`Backplate`, `controlPanelScreen`), либо собрать кресло из `Body_Cage` + подушки |
| Панель — плоский экран 0.20 × 0.13, в кадре почти не видна | смонтировать в стенную коробку 0.30 × 0.06 × 0.20 и добавить рамку; это примитив, не ассет |
| Стол — стальная рама на колёсах, без мягкого покрытия | накрыть ложем 1.90 × 0.75 × 0.08 (примитив) + ремни из `Arm and Leg Binders` |
| Модуль D — 110 324 полигона на одно колесо | децимация до ≤ 20k перед сценой; для блок-аута не критично |
| Стойка телеметрии — 0.19 м в ширину, тонкая | оставить как есть, это капельница-штатив; экраны навесить примитивами |
| Габарит стола 1.35 × 0.71 вместо 2.00 × 0.80 | `Table` имеет высокую раму (1.38 м), масштаб ограничен высотой; растянуть по X отдельно (непропорционально) |

## 2. Решения по ходу

1. **Капсула** — `Creature Tank`: цилиндр с прозрачной крышкой и станиной.
   Читается сразу и совпадает с ролью (вертикальная ёмкость с жидкостью).
   Единственная замена — цилиндр, а не «ложемент»: актив стоит, а не лежит.
2. **Модуль C** взят из GLB, а не из `.blend`: файл `tickle_chair_v1.blend`
   сохранён Blender 5.x (zstd), в 4.2 не открывается — импортируется только
   `converted/tickle_chair_v1.glb`. У мешей сняты армтура и модификаторы, иначе
   габарит не масштабируется.
3. **Модуль D** — большое колесо на станине из `GordProps` (там же мотор,
   I-beam, вентиляция): ротационный узел без авторской модели.
4. **Модуль B** — тележка `dildo_chair`: низкая станина 0.78 м с вертикальным
   приводом; подходит для «станка сзади».
5. **Модуль A** — сибиан-купол `BarbellSybian_V2`: закрытый купол с пультом,
   самый «фабричный» из всех.

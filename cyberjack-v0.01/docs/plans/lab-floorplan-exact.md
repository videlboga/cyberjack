## 9. Файлы и импорт в 3D

| Файл | Что внутри |
|---|---|
| `lab-floorplan.json` | комнаты (rect, h, kind), двери, объекты с монтажом и поворотом |
| `lab-floorplan.csv` | плоская таблица объектов для импорта скриптом |
| `lab-floorplan.svg` / `.png` | чертёж 1:100 для сверки |
| `tools/gen_lab_floorplan.py` | генератор (данные комнат и станков в начале файла) |

Порядок сборки сцены: полы по `rooms[].x0..y1` → стены из разностей прямоугольников → проёмы по `doors[]` → станки по `objects[kind=machine]` (поворот `rot`) → остальное по `mount` (floor ставится на z=0, wall — на высоту z, ceiling — под потолок). Единицы метры, Y-up конвертировать в Z-up на импорте.

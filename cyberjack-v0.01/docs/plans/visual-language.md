# Визуальный язык лаборатории «Омникрон» — аниме-сай-фай

**Актуальный стиль — инк-иллюстрация** (по рефу `public/backgrounds/laboratory/sex_machine.png`):
белые и почти белые заливки, тонкие серо-синие линии по каждой кромке, серые
«размывки» в стыках, цвет только в экранах и мелких приборах.

- Код: `docs/plans/tools/ink_lib.py` (материалы, свет, линии) + `ink_room.py` (сцена).
- Образец: `blockout/ink_room.png`, сравнение — `blockout/ink_vs_ref.png`.
- Палитра снята скриптом `tools/ref_palette.py` с рефа: `#EEF1F2 / #D8DDE0 / #C1C7CA /
  #9CA4A9 / #71797F`, насыщенность 0.04–0.06, контраст свет/тень 0.09.

Предыдущие итерации (не использовать для комнат): cel-shading «под Genshin»
(`toon_lib.py`, `anime_corner*.png`) и фотореалистичная клиника (`style_lib.py`).
Обе оставлены как история и для блок-аутов.

Правила плотности (главное отличие рефа от «мультика»):
1. Трубы идут в 2–3 плана: у стены, перед стеной, под потолком, с отводами и хомутами.
2. Кабели: пучки по полу и висячие от потолка к столу (кривые с провисом).
3. Каждая панель — со швом; каждый прибор — с рамкой, экраном и светодиодом.
4. Передний план обязателен: стойка, тележка, баллоны — они дают глубину.
5. Камера 3/4 из угла, 18–24 мм, на уровне глаз, с наведением на рабочий стол.

## 1. Принципы

1. **Плоско, в два тона.** Свет — кремовый, тень — синевато-лиловый. Полутонов нет,
   кроме металла (3 тона). Никакого PBR, грязи, фото-текстур.
2. **Контур — часть формы.** Инк по силуэту и изломам (Freestyle), 1.6–2.0 px.
   Контур отделяет объект от фона, а не подчёркивает каждую грань.
3. **Цвет держит композицию.** Кремовые поверхности + холодные металлические вставки +
   один светящийся акцент (бирюза). Второй акцент (янтарь) — только для меток.
4. **Светящееся светится.** Экраны, полосы, лампы, иллюминатор — emissive с мягким
   bloom. Это половина «аниме-вкуса», вторая половина — контур.
5. **Формы толстые и графичные.** Крупные скругления 30–80 мм, шпангоуты, рёбра,
   накладные рамки, толстые трубы. Тонкие детали — только акцент.
6. **Космос рядом.** Иллюминаторы, звёзды, холодный свет извне — напоминание, что это
   станция, а не офис.

## 3. Шейдинг

```
Diffuse(white) → Shader to RGB → ColorRamp(CONSTANT)
     [0.00] цвет × SHADOW_TINT × 0.58      (тень)
     [0.30] цвет                            (свет)
     [0.34] цвет × 0.80 (только металл)     (полутон)
  → + контровой (Mix ADD) → Emission 1.0
```

Правила:
- Порог света **0.30**: освещено сильнее — чистый цвет, иначе тень.
- Свет задаётся **вектором направления**, а не углами Эйлера
  (`Vector(vec).to_track_quat('-Z', 'Y')`) — иначе лампа светит не туда и вся сцена
  уходит в тень.
- **Тени от солнца выключены** (`use_shadow = False`): в интерьере потолок гасит всё,
  а для cel нужна ориентация поверхности, а не перекрытие.
- Emissive-материалы не участвуют в шейдинге: чистый Emission нужной силы.

## 5. Контур

- **Freestyle**: силуэт + рамка кадра + изломы (`crease_angle = 128°`), толщина 1.9 px,
  цвет `#0D0F1F`.
- Hull-контур (Solidify с флипнутыми нормалями) для панелей 20 мм **не годится** —
  съедает геометрию. Резерв только для толстых закрытых мешей.

## 6. Камера

- Обзор комнаты: 24 мм, высота 1.45–1.55, наклон 87–88°, поворот 3–12°.
- Деталь: 35–50 мм, дистанция 1.2–2 м.
- Каталоги: ортокамера, `ortho_scale` = ширина ряда + 0.9.

## 8. Что осталось от v1 (реализм)

- `style_lib.py` + `style_sheet.py` — PBR-материалы и линейка модулей для быстрых
  блок-аутов и проверки габаритов. В чистовых комнатах не применять.
- `room_kit.py`, `kit_devices.py` — геометрия комнат и устройств. Годятся: габариты,
  планы, проёмы не зависят от стиля.
- **CC0-ассеты (Poly Haven) для аниме-стиля не годятся**: текстуры обветренные,
  реквизит vintage (дерево, ржавчина). Скачаны в `assets/cc0/` (14 моделей, 6 текстур,
  2 HDR) и остаются на случай «запущенной» зоны; в аниме-сценах не используются.

## 9. Как пользоваться

```python
import sys; sys.path.append('docs/plans/tools')
from toon_lib import Toon

T = Toon()
T.build()                 # материалы в T.M
T.lights(sc)              # ключ + заливка + ambient
T.render_setup(sc, outline=False)   # Standard, bloom
T.freestyle(sc, thickness=1.9)      # инк-контур
T.apply(obj, 'wall')      # роль из таблицы §2
```

## 10. Чек-лист комнаты в аниме-стиле

1. Материалы — только из `Toon().build()`; ни одного PBR-материала.
2. Стены и пол — 2 тона, металл — 3, светящееся — emissive.
3. Один акцент `teal` на комнату + янтарные метки у опасных узлов.
4. Инк включён; проверить, что контур не съел панели и ручки.
5. Свет: ключ вектором, тени солнца выключены, ambient 0.22.
6. Пост: Standard, bloom 1.15/4, экспозиция −0.05.
7. Силуэт должен читаться как кадр аниме, а не как чертёж.

## 11. Технические грабли (проверено)

1. **AgX/Filmic убивают cel** — тона сереют, контраст пропадает. Только Standard.
2. **Тень от солнца в интерьере** гасит сцену через потолок → `use_shadow = False`.
3. **Freestyle без Line Style** падает (`ls.linestyle is None`) — создавать
   `bpy.data.linestyles.new()` и присваивать в `lineset.linestyle`.
4. **ngon-диск без UV**: процедурные текстуры берут одну точку → нужен
   `Texture Coordinate → Generated`.
5. **Voronoi-звёзды**: звезда — МАЛОЕ расстояние до центра ячейки; если поставить
   наоборот, диск становится белым.
6. **Hull-контур** на панелях 20 мм закрывает геометрию целиком — только Freestyle.
7. Emissive `cyan` на капсуле выглядит белым столбом: стекло — это `glass`
   (2 тона + контровой), а не свечение.
8. Свет через углы Эйлера не отлаживается на глаз: задавать вектором направления.

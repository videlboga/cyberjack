# Лебёдка: непрерывное раскручивание

Дата: 2026-11-10. Правка только `motion_winch` и winch-ветки viewer.

## Что заменено

Старая реализация скрывала/показывала `rope_turn_00…11` по порогам — это
читалось как покадровое добавление витков. Теперь в
`public/models/machine-modules/winch-rope.js` строится **один непрерывный
трубчатый трос** с постоянной топологией:

- вертикальная ветвь длиной `L` от `rope_payout` до касательной точки;
- непрерывная спираль вокруг оси барабана X;
- число витков `N(L) = 12 + (4 − 12) · L / 0,30`;
- шаг 0,0098 м, радиус навивки 0,0592 м, диаметр троса 0,0092 м;
- барабан и крюк/ферула/коуш синхронны с `L`;
- старые 13 rope-мешей скрыты один раз при загрузке, в кадре нет
  переключений `visible`.

## Замеры

| L, м | витков | длина спирали, м | конец ветви, м |
|---:|---:|---:|---:|
| 0,00 | 12 | 4,465 | 0,0328 |
| 0,15 | 8 | 2,977 | −0,1172 |
| 0,30 | 4 | 1,488 | −0,2672 |

- 200 кадров: `visible_writes = 0`, legacy mesh visible = 0;
- стоимость обновления ~0,32 мс/кадр;
- page errors 0, console errors 0, HTTP ≥ 400 — 0;
- 96 deep-link’ов: 96 canvas, 0 JS, 0 HTTP 404;
- bbox троса на L=0 и L=0,30 совпадает с bbox исходной навивки ±0,1 мм.

## Ограничение

При `L=0` крюк оказывается внутри кожуха навивки — это смещение
`rope_end` в исходной модели, а не ошибка намотки. Начиная с `L≥0,05`
крюк висит ниже барабана. Если нужно, крюк можно вынести отдельной
правкой модели, но это уже изменение геометрии, а не анимации.

# CJ-FIX-KIT — модульная матрица фиксации

Дата: 2026-11-11.  
Статус: концепция + состав набора. Не заменяет Mk-I; Mk-II/Mk-III остаются отдельными ассетами.

## 1. Принцип

Не делать одно «универсальное» устройство, которое пытается покрыть все позы.  
Собирать фиксирующий контур из стандартных модулей:

```text
BASE → MOTION → BODY INTERFACE → ACCESSORY
```

Поза не хранится в матрице. Матрица — это **набор деталей и правила сборки**, из которых под конкретную позу собирается контур.

## 2. Что не входит в набор

- рабочие головки, удары, вибрация, давление — это отдельный `EFFECT`-слой;
- мягкие ткани;
- автоматический подбор позы;
- 19 гнёзд в одном шарнирном узле;
- «все позы сразу».

## 3. Стандарты

| Стандарт | Назначение | Параметры |
|---|---|---|
| `CJ-RAIL-45` | структурный профиль | 45×45 мм, T-паз 10 мм, M8 T-гайка, шаг отверстий 50 мм |
| `CJ-NODE-45` | узел соединения | плита 120×120×12, 2–4 профиля, 2 болта M8 + штифт Ø6 |
| `CJ-LATCH-30` | жёсткое крепление тела | окно 48×34, палец Ø12 h8, WLL 5 кН, языки T-26/T-30/T-44 |
| `CJ-CUFF` | мягкий охват | существующие soft-манжеты; hard-варианты с CJ-LATCH-30 |
| `CJ-PAD` | опора | сменные подушки/ложементы |
| `CJ-QR` | быстрый съём | только для тела; структурные болты не QR |

**Не использовать D-ring как силовой интерфейс.** D-ring — гибкий якорь; для контура нужен жёсткий язык/защёлка или манжета с адаптером.

### 4.4. BODY — существующие компоненты

Набор не дублирует все манжеты. Он использует существующие:

- soft-манжеты: запястье, стопа, бедро, пояс, шея;
- hard-варианты: `*_hard` с CJ-LATCH-30;
- подушки: грудная, тазовая, подголовник;
- стремена и распорки.

Новые body-модули нужны только там, где нет совместимого адаптера.

|---|---|
| `fix_qr_pin` | быстрый палец для немассивных узлов |
| `fix_safety_pin` | вторичная фиксация |
| `fix_pad_set` | сменные подушки |
| `fix_cable_guide` | кабель/трубка, не силовой элемент |

## 5. Правила сборки

1. Длина рельса — 500/1000/2000. Не резать под позу.
2. В каждом стыке рельсов — узел, не голый болт.
3. Параллельные рельсы под каретки — шаг **≥250 мм**. При меньшем шаге — одна каретка на bay.
4. Каретка не ставится на рельс без стопора.
5. Стойка имеет опору пола и минимум две связи/раскоса.
6. Вынос 500 — без раскоса; 800 — только с раскосом.
7. Body interface ставится через адаптер и каретку/поворотный узел, не прямо на рельс.
8. Вокруг защёлки — свободная зона 100 мм для рычага и руки.
9. Одновременно активно не более **12** body interfaces.
10. Манжеты не являются несущей частью рамы.
11. Контур не должен держаться на теле: сначала рама, потом крепления.
12. Наклонная спинка фиксируется в 0/30/60/90°, не «примерно».

## 6. Типовые контуры

### 6.1. Лежачий `contour_bed_1000x2000`

- 2× `fix_rail_2000`, 4× `fix_cross_1000`, 4× `fix_corner_node`, 4× `fix_foot`;
- 6× `fix_carriage`, 4× `fix_cuff_adapter`, 2× `fix_latch_adapter`;
- 4 soft cuffs (запястья/стопы), 1 тазовая подушка;
- опционально `fix_spreader_600`.

Даёт: регулировку по длине, ширине, 4 конечности, таз.

### 6.2. Полулежачий/вертикальный `contour_recline`

- 4× `fix_post_1000`, верхняя рама, 2× `fix_boom_500`, `fix_backboard`, `fix_tilt`;
- 4× `fix_carriage`, 2× `fix_pivot`, 4× `fix_cuff_adapter`;
- грудная/тазовая подушки, 2 боковых крепления.

Даёт: наклон 0/30/60/90°, руки сбоку, ноги на нижней поперечине.

### 6.3. Сидячий `contour_seated`

- рама 1000×1000, 2 стойки, сиденье, спинка;
- 2 бедренных манжеты, 2 стопы, 2 запястья;
- `fix_spreader_600` для коленей.

### 6.4. Раздвижной `contour_spreader`

- `fix_spreader_600/900` + 4 `fix_latch_adapter`;
- 4 hard cuffs;
- без общей рамы, если нагрузка допустима.

### 6.5. Подвесной `contour_suspension`

- верхняя балка, 2 `fix_riser`, 2 `fix_pivot`;
- 2 suspension cuffs;
- вторичные safety pins;
- обязательная проверка «нельзя опереться на манжеты».

| Вход | Выход | Адаптер |
|---|---|---|
| CJ-RAIL-45 | CJ-RAIL-45 | `fix_corner_node`, `fix_t_node`, `fix_cross_node` |
| CJ-RAIL-45 | CJ-LATCH-30 | `fix_latch_adapter` |

| CJ-RAIL-45 | эффект | **не входит**; отдельный EFFECT-слой |

## 8. Проверки

### Модуль

- 4 рендера: 3/4, фронт, бок, крупно интерфейс;
- bbox, масса, материал, интерфейсы, DOF, нагрузка;
- палец/штифт входит в отверстие, а не «стоит рядом»;
- рычаг и рука не перекрыты;
- нет плавающих деталей.

### Сборка

- соединения по именованным интерфейсам, не по bbox;
- проверка всех состояний кареток, а не по одной;
- шаг рельсов и ширина каретки проверены арифметикой до модели;
- зазор 100 мм у защёлки;
- 12 активных interfaces;
- контур стоит на полу/раме, а не на теле;
- нет проникновения в тело на ходе.

### Приёмка

- модуль: 0 проникновений, интерфейс подтверждён;
- сборка: 0 коллизий в одновременных крайних состояниях;
- body mount: ≤5 мм, ≤5°;
- старые Mk-I/Mk-II/Mk-III не ломаются.

## 9. Первый выпуск (MVP)

Собрать 8 модулей:

1. `fix_rail_1000`
2. `fix_rail_2000`
3. `fix_cross_1000`
4. `fix_corner_node`
5. `fix_foot`
6. `fix_post_1000`
7. `fix_carriage`
8. `fix_latch_adapter`

Плюс один тестовый контур `contour_bed_min`:

- 2× rail_2000, 2× cross_1000, 4× corner, 4× foot;
- 4× carriage, 2× latch_adapter;
- 2 hard cuffs.

Только после этого — pivot/tilt/boom/backboard.

## 10. Что должно появиться в каталоге

Отдельное семейство `CJ-FIX-KIT`, не смешивать с 96 старыми компонентами:

- карточка модуля: класс, стандарт, размеры, масса, интерфейсы, DOF, нагрузка;
- схема совместимости;
- сборки-примеры;
- статус `concept / built / verified`;
- ссылка на Mk-II/Mk-III как на legacy, не как на «универсальную» замену.

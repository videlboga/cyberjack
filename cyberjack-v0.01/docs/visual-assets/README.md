# Матрица изображений персонажей

Исходное описание матрицы находится в `src/infrastructure/data/visual/character-image-matrix.json`.
После его изменения выполните:

```bash
npm run build:image-matrix
```

Генератор создаёт:

- `character-image-combinations.csv` — все допустимые итоговые сочетания;
- `character-image-source-checklist.json` — перечень исходных PNG по слоям;
- `character-image-matrix-summary.json` — количество вариантов.

## Единый формат

- холст: 1024×1536;
- фон: прозрачный;
- привязка фигуры: нижняя точка по центру;
- запрещены индивидуальные обрезка, масштабирование и смещение между слоями одной позы;
- тело содержит персонажа и выраженное состояние;
- одежда и фиксация сохраняются отдельными прозрачными слоями;
- если ремень должен проходить и за телом, и перед ним, используются два файла с суффиксами `__back` и `__front`.

Пример итогового сочетания:

```text
public/character-images/rendered/mira/kneeling__lab_gown__handcuffs__guarded.png
```

Соответствующие исходники:

```text
public/character-images/source/mira/body/kneeling__guarded.png
public/character-images/source/mira/clothing/kneeling__lab_gown.png
public/character-images/source/mira/restraint/kneeling__handcuffs.png
```

## С чего начать

Для первой проверки интерфейса достаточно Миры в трёх позах (`standing`, `kneeling`, `lying`), трёх состояниях (`neutral`, `high_positive`, `unconscious`), двух вариантах одежды (`nude`, `lab_gown`) и двух вариантах фиксации (`none`, `handcuffs`). Это 9 изображений тела и 9 прозрачных слоёв вместо изготовления всей матрицы.

`unconscious` в свободной позе следует рисовать только лёжа. Остальные строки сохранены в полной матрице как технические переходные кадры: движок может сначала зафиксировать отключение и лишь затем сменить позу.

## Почему не все устройства сочетаются со всеми позами

Матрица отбрасывает физически невозможные сочетания. Подвес существует только в позе `suspended`, ремни стола — только лёжа, стационарная рама — стоя или с разведёнными конечностями. Наручники, ножные манжеты, повязка и кляп остаются переносимыми контекстами.

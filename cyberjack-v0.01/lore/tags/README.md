# Custom Tag Sets

Любые JSON-файлы в этой директории автоматически подхватываются генератором персонажей.

Минимальный формат:

```json
{
  "world": [
    {
      "id": "world_new_fact",
      "title": "Новый слой мира",
      "summary": "Короткое описание",
      "stKeywords": ["ключ1", "ключ2"],
      "loreRefs": ["uid_из_lore_json"],
      "personaHooks": ["Поведенческая заметка"],
      "narrative": {
        "identity": ["Фразы для блока идентичности"],
        "history": ["Фразы для истории"],
        "activation": ["Как персонаж стал активом"]
      }
    }
  ]
}
```

- Поле `level` можно не указывать, если описание лежит в соответствующем разделе (`world`, `faction`, `origin`, `event`, `trait`).
- Можно хранить всё в одном массиве `tags`, тогда для каждого элемента нужно задать `level`.
- `loreRefs` должны совпадать с `uid` записей из `lore/*.json`.
- При совпадении `id` кастомный тег перезапишет базовый.

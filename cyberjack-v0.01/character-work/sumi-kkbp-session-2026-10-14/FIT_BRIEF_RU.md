# Sumi — fit-brief для Koikatsu Chara Maker

Реф: `sumi-session-2026-10-07/references/portrait-neutral.png` (+ standing-costume-neutral.png)
Источник: KKS EX BetterRepack R6, старт с чистой бланк-карточки (новый персонаж).

## Целевой облик (по портрету)
- **Волосы**: короткое объёмное каре; прямая «тупая» чёлка на лоб (пряди между глаз);
  концы по бокам закручены в тугие спиральные завитки (corkscrew curls) наружу.
  Цвет: пастельно-розовый, светлее сверху (глух. #F8C9D4), тени/низ чуть глубже #E8A0B8.
- **Глаза**: большие, выразительные; радужка малиново-розовая #E87A90; густая тёмная верхняя
  ресница; крупные блики («стеклянные» глаза). Взгляд прямой, нейтрально-мягкий.
- **Лицо**: фарфоровая светлая кожа с тёплым подтоном; нос маленький;
  рот — маленькая нейтральная линия; лёгкий румянец (#FFB6C1-ish) как полосы/шотхэтчет под глазами —
  если в мейкере есть blush-слой, включить слабый.
- **Тело**: petite: рост чуть ниже среднего, узкие плечи, тонкая шея, стройная;
  голова крупная относительно тела (доля ~1:5.5 по исходной nude-оценке — не пугаться).
- **Одежда**: белое камисольное платье (тонкие бретели, матовый белый);
  ожерелье-цепочка с розовым сердцем-кулоном (#FF69B4) в Accessory.

## Что НЕ трогать без проверки
- Не использовать sample1/sample2 как базу лица (причёска/цвета не совпадают) — только чистый бланк.

## Экспорт (после фита)
- Отключить мигание (maker), поза = T-pose (мод Character Maker Poses), KKBP Export.
- Выход в `~/.wine-kks/drive_c/koikatsu_model/...` — заберусь сам.

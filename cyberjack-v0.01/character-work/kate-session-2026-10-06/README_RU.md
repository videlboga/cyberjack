## Структура

- `session/outputs/` — все результаты, модели BLEND/GLB/FBX/OBJ, рендеры, видео, документы, полный UE-проект с Content/Config/Plugins и сохранёнными рабочими данными.
- `session/work/` — все исходные скрипты, логи, промежуточные данные, исходники и сборки helper-плагина, инструменты ранних этапов.
- `source-models/` — внешние донорские модели из Загрузок, упомянутые пользователем.
- `references/character-images/` — референсы Кейт с сохранением названий категорий.
- `external-notes/` — инструкция кастомного MetaHuman и отчёт другого агента по Суми.
- `TRANSFER_REPORT.json` — карта каждого источника и места копирования.
- `VERIFY_REPORT.json` — итог проверки содержимого.
- `FILE_MANIFEST.jsonl` — перечень файлов и размеров.

Полная установка Unreal Engine и Blender остаётся внешней зависимостью. UE-проект включён; сам движок, его Core Data и установочные архивы сюда не дублировались. Проверенные версии: UE5.8.2 и Blender5.2.1 LTS.

## Перенос путей

Скрипты и старые документы сохраняют исходные абсолютные пути. Это архив оригиналов, не переписанный универсальный пайплайн. В этой системе старые пути outputs/work продолжают работать через символические ссылки. При переносе на другую машину адаптировать пути по TRANSFER_REPORT.json; основной старый workspace соответствует новой папке `session/`. Пути `/Game/...` внутри UE сохраняются. Скрипты, использующие старые пути outputs/work, теперь записывают через ссылки в этот же архив; перед экспериментом делать отдельную рабочую копию.

В копии есть отвергнутые эксперименты, старые сборки, логи и кэши: выбирать рабочие версии по гайду, не по максимальному номеру. Полный поздний персонаж не прошёл все production-проверки; ограничения записаны в гайде.

Для удобства в корне есть относительные ссылки `UE/` на каталог проекта и `GUIDE_RU.md` на подробный гайд.

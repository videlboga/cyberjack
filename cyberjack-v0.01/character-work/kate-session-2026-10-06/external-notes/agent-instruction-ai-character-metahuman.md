# Агентная инструкция: AI-персонаж → анимированный MetaHuman (UE 5.8)

Источник: Stefan 3D AI — «Turn ANY Character into an Animated Metahuman - Full AI Workflow»
https://www.youtube.com/watch?v=4w7oA4oJMqs (28:22, главы в описании).
Пайплайн проверен автором на 4 персонажах разной сложности; базовое время ~1 час на персонажа.

## Пререквизиты (проверить до старта)

1. Unreal Engine 5.8. Options → убедиться, что «MetaHuman Creator Core Data» установлен (иначе галочка + Apply, докачает сам).
2. Все MetaHuman-плагины включены, движок перезапущен.
3. Blender (бесплатный) — сборка, запекание, риггинг аксессуаров.
4. Шаблон «MetaHuman Conform» (size reference) — бесплатно на Fab (ссылка в описании видео).
5. Генератор 3D: Tripo AI (у автора работает лучше всех; можно любой другой).

## Этап 1. Подготовка исходного меша (генерация + Blender)

1. Сгенерировать ТЕЛО в HD-качестве (не Smart/Low-Poly): тело — референс для переноса цвета и нормалей, детализация нужна высокая. Текстуру генерировать в 8K, перед работой ужать до 4K (память).
2. Позовные требования (критично для конформа): зазор между ногами, подмышки не прижаты к телу, все пальцы раздельные. Поза не важна — важно расстояние.
3. ГОЛУВА генерируется отдельно (точность деталей). Без ресниц. Без волос — лысая голова, иначе конформ обтянет форму волос и череп будет странным.
4. Волосы, борода, украшения — отдельными ассетами. Исключение: если нужна бесшовная стыковка волос с кожей (дреды) — «ветки» на голове оставить, уши/ветки должны прийти отдельным мешем.
5. В Blender: соединить голову+тело в ОДИН меш (Join), разрешение не оптимизировать — оставить high-poly. Пальцы раздельные, поза поправлена (Pose Mode).
6. В ту же сцену добавить Conform-шаблон с Fab: подогнать по размеру, Ctrl+A (Apply Scale & Rotation), трансформы = 0/1 (локация любая). Это размерный эталон для конформа.
7. Экспорт GLB (статичный меш, настройки по умолчанию).

**Готово, когда:** один цельный high-poly меш с раздельными пальцами, лысый, поза А-поза с зазорами; GLB экспортирован.

## Этап 2. Конформ в MetaHuman (UE)

1. Проект Third-Person. В Characters создать папку персонажа, перетащить GLB, импорт по умолчанию.
2. Создать MetaHuman-персонаж в той же папке, открыть. Вкладка Import → «From Custom Mesh» (первая), перетащить статичный меш в слот Combine Mesh (ввод раздельными head/body автору неудобен — использовать combined).
3. Auto Solve (включить Matcap для наглядности). На 4070 Super ~2 минуты. Результат — MetaHuman, повторивший кастомный меш.
4. СРАЗУ: Manual Solve → **Save Pose** — сохранить DNA-файл в папку персонажа. Это фиксирует меш в сконформленной позе; в следующей вкладке поза меняется, а для запекания нужна именно исходная. Пропуск = невозможность запечь текстуры.
5. Вкладка пропорций: подправить глаза/части лица — опционально.
6. Вкладка Materials: тона кожи не нужны (текстуры свои); можно настроить глаза/зубы.
7. Вкладка Hair/Clothing — пропустить (кастомный персонаж).
8. Финал: **Create Full Rig** (долго) + **Download Texture Sources**. Компилирует MetaHuman и сохраняет локально. Процесс обратим: можно вернуться и заново экспортировать DNA.

**Готово, когда:** в папке MetaHuman появился персонаж; синимпринт ставится в сцену (пока в дефолтных текстурах — это нормально).

## Этап 3. Текстуры запеканием (Blender Cycles) — путь A, полный контроль

1. Из сохранённого DNA: **Generate Skeleton Mesh** → Asset Actions → Export (FBX). Это меш в сохранённой позе с теми же UV.
2. В Blender он идеально ложится на исходное тело. Проблема: MetaHuman использует UDIM, Blender не печёт через UDIM. Починить:
   - голову выделить в UV-редакторе (Sync) → P → Separate Selection — отдельный объект;
   - UV тела сдвинуть ровно на −1 (как UDIM-тайл) — без этого запекание не взойдёт.
3. Запекание из исходного тела в MH-меш, Cycles, Selected to Active (сначала исходник, потом цель, правильная текстура выбрана в материал-редакторе):
   - цвет: Bake Type = Diffuse, только Color;
   - нормали: Bake Type = Normal.
4. Стык на шее: в исходнике подправить Hue/Saturation под цвет тела и перепечь; мелкие артефакты — Clone/Smear кисти в Texture Paint на цвете и нормалях.
5. В UE: папка MetaHuman → Body → Baked — заменить текстуры тела, затем головы (в материале MetaHuman). Демо-кейсу хватает LOD0; для продакшена заменить во всех LOD.

**Готово, когда:** персонаж в UE выглядит как кастомный, стыки головы/тела не видны.

## Этап 4. Кастомная голова/аксессуары (риппинг поверх)

1. Взять skeleton mesh ФИНАЛЬНОГО MetaHuman (не тот, что для запекания): тело и лицо отдельно, экспорт вместе со скелетом/арминой.
2. Голова в Blender: скрыть корневые кости (там весь лицевой риг на костях), скульптингом подогнать свой ассет под MH-голову.
3. Оптимизировать: Decimate (или сразу low-poly при генерации).
4. Именование + парент: выделить объект + арматуру (Shift) → Parent → **Armature Deform** (Ctrl+P).
5. Веса: Weight Paint → выбрать кость head → Weights → Set Weight (100% на head; лицевые кости не нужны). Если ассет закрывает анимируемую зону лица (брови) — переносить веса честно. Для тела простой перенос весов с MH-тела работает хорошо.
6. Арматуру назвать **root** (обязательно).
7. Экспорт FBX: выделены только арматура+объект; текстуры НЕ экспортировать; в Armature — **Add Leaf Bones выключено** (иначе скелет не совпадёт); Geometry — Smoothing Groups; Selected Objects Only.
8. Импорт в UE. Если нормали пеклись в Blender/Marmoset — в настройках импорта текстуры **Flip Normal Map Green Channel**.
9. Привязка: синимпринт MetaHuman → Components → перетащить skeleton mesh на слот Body. Скелет совпадает, веса заставляют ассет двигаться с анимацией.
10. Объёмные детали тела: дублировать MH-тело, выдавить в скульпте, отделить в отдельный объект, экспорт обратно; материал тот же.

**Готово, когда:** аксессуар сидит на персонаже и едет вместе с анимациями.

## Этап 5. Без запекания: AI-текстурирование по MH-UV — путь B (стилизация/toon)

Когда нормал-мапа не нужна (мобильные/toon-игры):

1. Конформ обычный, но **Save Pose пропускаем** (запекать нечего), в материалах настраиваем только глаза/рот.
2. Взять skeleton mesh финального MH (поза MetaHuman), тело и голову, экспорт со скелетом.
3. В Blender: у головы по материалу faceSkin — Select по материалу → Separate → удалить всё лишнее (ресницы, рот и пр.). Тело — один материал. UV тела сдвинуть на −1 (UDIM), иначе AI-текстуринг не сойдётся.
4. Экспорт GLB (скелет не нужен). В Tripo: импорт, **Rotation 90**, «Use Original UV» НЕ выключать — вся суть в MH-UV.
5. Отдать в AI-текстуринг с исходным референсом персонажа → на выходе отдельные текстуры для тела/головы/волос, точно следующие UV. Стыков не существует вообще.
6. Текстуры в UE, заменить. Волосы/уши — через веса как в этапе 4 (статичными объектами с материалом).
7. Дополнительно можно накатить Toon-шейдер.

**Готово, когда:** текстуры заменены, стыков нет, стилизация держится.

## Этап 6. Анимация: markerless mocap + Live Link

1. Fab → «MetaHuman Animator Markerless Motion Capture» — установить плагин, перезапустить UE, убедиться, что включён (по умолчанию не виден).
2. Live Link Hub → **Mono Video Ingest** → указать папку с видео → Add to Queue → результаты в Capture Manager Imports.
3. Создать **MetaHuman Performance** ассет → Footage Capture Data → выбрать обработанное видео. Window → Image Review — включить, чтобы видеть референс рядом с анимацией.
4. В Settings включить **Body Tracking** (доступен только с плагином) → выбрать синимпринт MetaHuman.
5. Обработать. Нагрузка на GPU зависит от разрешения: 1K идёт плавно, 4K не кормить.
6. Результат: полная анимация тела+лица; экспортируется как обычная анимация в игру. Лицевой риг дополнительно работает через Live Link с телефона (Face Capture).

**Готово, когда:** персонаж повторяет движение из видео-референса; анимация экспортируется.

## Типовые ошибки и лечение

| Симптом | Причина | Лечение |
|---|---|---|
| Странный череп после конформа | Волосы на голове в исходнике | Генерить лысой; волосы отдельным ассетом |
| Auto Solve путает пальцы (2 вместо 4) | Сложная геометрия кистей | Reset Body → вручную расставить маркеры (Ctrl+ЛКМ/ПКМ, Shift добавляет точки), привязать к телу → Solve Body. Для лица так же |
| Запекание не работает | UV в UDIM-пространстве | Сдвиг UV тела на −1, голову отделить |
| Скелет не совпадает при импорте FBX | Add Leaf Bones включён | Выключить, переэкспортировать |
| Нормали выглядят вывернуто | Green channel | Flip Normal Map Green Channel при импорте |
| Нужной позы нет для запекания | Save Pose не сделан после Auto Solve | DNA сохранять сразу после солва (этап 2.4) |
| Mocap трешит/тормозит | 4K референс | 1K видео |
| Аксессуар не анимируется | Веса/парент | Armature Deform + веса на нужную кость; арматура = root |

## Порядок обхода для агента

- Простейший тест пайплайна: персонаж типа «балерина» (без волос, простые пропорции) — путь B без запекания.
- Полный цикл с контролем текстур: путь A (Blender Cycles), нормали и стыки дорабатывать кистями.
- Сложные причёски/ветки: держать бесшовный переход (этап 1.4), запекание обязательно путь A.
- Нормы времени: базовый цикл ~1 ч/персонаж; итерации деталей сверху.

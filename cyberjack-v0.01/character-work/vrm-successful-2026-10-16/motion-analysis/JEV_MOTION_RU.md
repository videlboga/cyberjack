# Jev для семантической проверки движений

Путь: локальный E5 → 24 уникальных текста кандидатов → Jev → проверка движения,
суставов, условий команды и пола. Свободный запрос действия сохраняется.
Jev не строит траектории и не подтверждает физику по тексту.

`tools/jev-motion-verifier.mjs` использует OpenRouter Decisions API
https://openrouter.ai/api/alpha/decisions с моделью `typesafe/jev-1.13`.
Ключ читается из существующего серверного окружения; в браузер не передаётся.
Один пакет независимых Noul-вопросов, каждый со своим кандидатом и общим запросом.
Ответы проверяются строго: пропущенный ответ/неверный тип/NaN не становится согласием.

По умолчанию включён Jev. `MOTION_VERIFIER=llm` возвращает прежний verifier.
`MOTION_JEV_MODEL` меняет модель, `MOTION_JEV_THRESHOLD` меняет порог (по умолчанию .8).
Порог предварительный, не откалиброван на независимой размеченной выборке.
Если никто не прошёл порог, но есть вероятность >=.2, запрос передаётся LLM.
Ошибки API тоже явно отмечаются как fallback. Уверенный отрицательный ответ не
подменяется положительным через резервную модель. Геометрический отсев сохраняется.
Во вьювере показывается поставщик проверки; подробности, fallback, вероятности
и модель доступны в деталях результата. Кэш разделён по verifier/model/threshold.

## Пробы
`node --test tools/jev-motion-verifier.test.mjs tools/motion-semantic-search.test.mjs tools/terminal-motion.test.mjs`
`node tools/jev-motion-benchmark.mjs`

`artifacts/jev-motion/comparison-initial.json`: первая формулировка отвергла всё,
хотя ответила быстро. Этот провал сохранён.
`artifacts/jev-motion/comparison.json`: после уточнения вопроса о намерении клипа:

| Запрос | Jev, мс | LLM, мс | Результат Jev |
|---|---:|---:|---|
| eat food | 520 | 3643 | f eat 00 06 L |
| wave hello with hand | 522 | 3781 | Waving Gesture, Waving 1–4 |
| reading a book | 462 | 1260 | нет подтверждённых кандидатов |

Замеры сделаны параллельно на одном небольшом наборе. Это не оценка точности
на всём корпусе и не обещание задержки всей команды. Разбор естественного языка
остаётся отдельным LLM-вызовом. Геометрия может отвергнуть смыслового кандидата.

Документация: https://docs.typesafe.ai/primitives/noul
https://openrouter.ai/docs/api/api-reference/alphadecisions/submit-a-decisions-request

Проверка в интерфейсе: «Помаши рукой в знак приветствия, сохраняя текущую позу»
выбрала Waving Gesture, отображается «Проверка смысла: jev» без fallback.
Весь запрос 6.89 с: языковой разбор 6.24 с, дальнейший план 0.60 с.
Интеграционные тесты также подтвердили f_eat_00_06_L, Waving Gesture и idle
после посадки. Следующее узкое место — общий языковой разбор, не retrieval.

# Речь и язык

Во вьювер добавлена панель «Речь и язык · Koikatsu». Выберите локальный аудиофайл и нажмите Play в аудиоплеере. Рот управляется громкостью; форму рта можно выбирать в панели лица. Пауза/окончание освобождают управление и восстанавливают прежнюю форму. Аудиофайлы остаются локальными, на сервер не отправляются.

Это перенос FBSAssist.AudioAssist: 1024 отсчёта, RMS × чувствительность (по умолчанию 2), clamp 0…1, подъём (raw + previousRaw)/2, спад raw×0.2 + previousRaw×0.8. WebAudio получает отсчёты микшера браузера, поэтому результат не обязан побитово совпадать с Unity GetOutputData. Готовые фонемные дорожки A/I/U/E/O здесь не заявлены: форма выбирается вручную, аудиодрайвер меняет открытие. Случайное изменение ширины рта из FBSCtrlMouth не перенесено. Сохранён исходный код AudioAssist в ../native-code/.

Язык: 2 оригинальных клипа ptn01/ptn02 из chara/oo_base.unity3d (tang2_anime) и 114 уникальных имён Sita_* из h/anim/parts/{01_00,71_00}.unity3d. Копии исходников по-прежнему сохранены в полной библиотеке. 114 клипов относятся к отдельному игровому ригу osawari_tangAvatar, а не к ригу персонажа. Их хеши разрешены по исходному Avatar из h/common/01.unity3d. Это ретаргет деформации языка, без игровой сцены, партнёра, размещения предмета и IK контакта. Общие helper-кости влияют на поворот, их сценовое перемещение не переносится в положение головы. Не все клипы в изоляции дают заметное движение.

В исходных VRM присутствовали кости языка, но не взвешенная к ним скрытая сетка. Сетка Tongue (rigged) извлечена из сохранённых Blender-файлов (246 исходных вершин; GLB может разделять вершины по UV/нормалям). Два небольших GLB в assets/ содержат геометрию, UV, веса и сокращённый скелет. При загрузке они используют клонированный исходный материал KK cf_m_tang с текстурами текущего VRM. Привязка следует голове; вращения переносит world-space delta с отражением Unity→VRM, позиции — дельта от rest pose с масштабом длины цепочки. Штатная статичная сетка языка скрывается на время, затем восстанавливается. Кнопка «Убрать язык» возвращает прежнюю форму рта. Речь и язык по очереди владеют ртом. Анимация тела и SpringBone продолжаются независимо.

Каталог содержит исходные rest poses, точные хеши путей, ссылки на неизменённые нативные клипы и происхождение. Повторное извлечение каталога: `python3 facial-control/performance/tools/extract.py` из любого каталога (UnityPy). Для сетки: `/usr/bin/blender -b characters/mira/Mira_outfit_00.blend --python facial-control/performance/tools/export_tongue.py -- facial-control/performance/assets/mira-tongue.glb` из корня пакета; для Rin — characters/rin/outfits/Rin_outfit_00.blend и rin-tongue.glb. Исходные VRM/.blend не изменены; контрольные суммы проверены в reports/models-unchanged.json.

API: `window.__studio.performance.playTongue(id)`, `.stopTongue()`, `.seek(seconds)`, `.audio`, `.state`; список ID — `.catalog.clips`. Отдельная сетка существует только во вьювере: сами VRM не приобретают новые клипы или геометрию при открытии в сторонней программе.

Связи и исходные последовательности теперь доступны в отдельной панели «Связанные действия · Koikatsu» и каталоге `../../animation-links/`. Там же — воспроизведение исходного tang2_anime и ручной просмотр связанных слоёв тела/языка.

# Rin — четыре комплекта

Конвертация нового KKBP-импорта Rin_alloutfits.blend из исходного экспорта 20261015221708_春野千佳.

- Rin_outfit_00.vrm — топ, длинная юбка, очки.
- Rin_outfit_01.vrm — платье.
- Rin_outfit_02.vrm — рождественский комплект.
- Rin_outfit_03.vrm — без одежды; это штатный четвёртый вариант исходника.

Каждый комплект — самостоятельный VRM 1.0 с текстурами внутри файла. Переключение во вьювере загружает соответствующий файл, сохраняя позу. Для тела каждого комплекта применяется его исходная cf_m_body_AM_XX.png (зелёный канал, как в используемом KKBP-шейдере). Общие светлая и теневая текстуры тела исходника одинаковы во всех четырёх вариантах.

Сохранены кости, веса, морфы и исходное разрешение текстур. DynamicBone перенесён в VRM SpringBone по JSON исходника; это приближение поведения исходного движка. Записи физики с Weight=0 не включаются. Альтернативные состояния частично снятой одежды не накладываются на основные комплекты.

Вариант 03 не потерян: у него все Clothes.Parts.Id равны нулю, а ClothingData не содержит рендереров одежды. KKBP ожидаемо удалил пустой Outfit03. Экспорт включает тело и Hair Outfit03.

Рабочие предыдущие VRM сохранены. Новые файлы и скрипт находятся в отдельной директории.

Физика отфильтрована по CoordinateType: 12 активных цепочек у 00 (волосы и юбка), по 4 у 01–03 (волосы). Исходные определения волос и коллайдеров одинаковы во всех координатах; дубликаты не суммируются.

Восстановлены правила видимости игры: NotBra=1 у верха00 скрывает бельё (его геометрия сохранена отдельным скрытым объектом в .blend). У комплекта02 восстановлены alpha белья и исходная маска бюстгальтера; прозрачные участки больше не рисуются чёрными.

После проверки в позах комплект00 получил полные цепочки юбки и четыре капсулы ног из Rin_restored_v2.vrm. Это устраняет проверенное прохождение колена сквозь юбку при Stand_00_00. Настройки волос из нового источника сохранены. Всего00: 12 цепочек, 41 коллайдер; 01–03: 4 цепочки, 37 коллайдеров.

Воспроизведение: convert_four_outfits.py, затем finish_skirt_physics.py и sync_four_outfit_skirt.py (через /usr/bin/blender для скриптов с bpy). fix_game_clothing.py — отдельная процедура исправления уже экспортированных промежуточных00/02; основной конвертер уже содержит эти правила.

Проверки: glTF validator — 0 ошибок во всех четырёх файлах (предупреждения MToon/unlit и касательных сохранены в validation.json). Переключение всех комплектов с сохранением позы/таймлайна, совместимость прежней модели и JavaScript — без ошибок. После финального изменения физики00 отдельно проверены все7 idle-поз: матрицы и симуляция конечны. Скриншоты preview_00..03.png.

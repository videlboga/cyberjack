## Поиск

```bash
python3 query.py --stats
python3 query.py -q сидя --category action --limit 10
python3 query.py -q Walk --exact
python3 query.py --source Katarsys --limit 10
python3 query.py -q WLoop --rig female --no-dupes
```

`glossary.json` даёт подсказки по именам и русский поиск. Это не визуально проверенная разметка сцен. Неизвестные коды сохраняются. L/M/S считаются метками вариантов; их универсальное значение не установлено.

## Точные повторы

Проверено 56978 файлов, ошибок чтения 0. Получено **48339 групп точного содержимого с учётом контекста**. Это не число визуально различных движений: разные настройки, риги или контекст ссылок сохраняют отдельные группы.

`find_duplicates.py` сравнивает SHA256 канонического полного clip без m_Name, риг и разрешённые binding paths. Для предметов, событий и PPtr учитывается исходный файл, поскольку одинаковые Unity pathId в разных файлах могут ссылаться на разные объекты. Приближённое сравнение движений не применяется.

`duplicates_report.json` хранит `dedupe.keep`: представитель → aliases. Все исходные клипы и имена сохранены. В CLI и вьювере повторы скрываются **после** фильтров; представитель выбирается среди совпавших клипов, поэтому категория/риг/имя не теряются. Индекс привязан fingerprint к текущему каталогу; устаревший индекс не применяется.

```bash
python3 find_duplicates.py --workers 4
```

`duplicates_hashes.jsonl` — кеш проверенных payload по размеру/времени и контексту. `catalog-0..7.json` и `import-0..7.jsonl` — части/состояние параллельного импортера; основной индекс — `catalog.json`. Нельзя заключать о полноте библиотеки только по уже импортированным бандлам: нужна сверка со всей инвентаризацией.

## Файлы и воспроизведение

`clips/<id>.json.gz`: `koikatsu-native-v1`, полные native-поля AnimationClip. Основные каналы находятся в `clip.m_MuscleClip.m_Clip.data`, а не обязательно в пустых `m_RotationCurves`. Большие массивы закодированы base64 как исходные u32/f32, без пересэмплирования. `sources/` сохраняет исходные Unity assets. `mod_map.json` и `supplemental_provenance.json` дают настоящие архивы и entries для безопасных хэш-имён.

Вьювер читает только выбранный клип. Положения, вращения и масштабы основного скелета переносятся на Rin/Mira с сохранением SpringBone. Для KKBP/PMX используется mirror-X `[x,-y,-z,w]` и мировые дельты через иерархию. Анимации предметов/камеры и прочие каналы сохранены и доступны для скачивания JSON. Unity-сценарии, IK сцены, переходы AnimatorController и контакт с партнёрами/мебелью не исполняются в VRM-плеере.

Проверка прежнего README, глоссария и дедупликации: `../reports/animation-library-audit/review.json`. Предыдущие версии сохранены там в `previous/` как исторические материалы.

# Библиотека анимаций Koikatsu Sunshine

Импортировано **56978 AnimationClip** из установленной игры: стандартные abdata, zip/zipmod, отдельные мод-бандлы и сериализованные ресурсы Player Data. Полнота прохода и ошибки перечислены в `audit.json`, `tools/animation-library/inventory/summary.json` и `supplemental-summary.json`. Имена могут повторяться: каждый объект сохранён отдельно по паре источник/pathId.

`catalog.json` — каталог с категориями, именами, длительностью, происхождением и ссылками на клипы. `clips/*.json.gz` — полный AnimationClip typetree с настройками, событиями и каналами. Большие массивы упакованы без изменения исходных 32-битных значений: `u32le-base64` для streamed data, `f32le-base64` для dense/constant data. Остальные поля сохранены; нечисловые значения float представлены объектами `nonFinite`, байтовые поля — `bytes-base64`. `sources/` — исходные Unity bundles/serialized assets; `supplemental_provenance.json` связывает безопасные имена с ZIP-архивами и entries. Проприетарная игра для просмотра этих сохранённых кривых не требуется.

Во вьювере работают поиск по имени/источнику и русскому глоссарию, безопасное скрытие точных повторов после фильтров, категории, выбор исходного рига, фильтр движений для VRM, страницы по30клипов и загрузка выбранного клипа по запросу. Избранные прежние12циклов находятся в сворачиваемом разделе. Исходный риг определяется по происхождению/именам, это классификация для поиска.

Перенос на Rin/Mira поддерживает native streamed cubic, dense linear и constant каналы положения, quaternion/Euler вращения и масштаба. Сохраняются пропорции модели и физика SpringBone. Циклический режим берётся из Unity m_LoopTime; одноразовый клип останавливается в конце. При смене одежды сохраняются клип, время и пауза.

55166 клипов содержат распознанные каналы основного скелета и доступны для переноса на VRM. Остальные доступны при выключенном фильтре «Для персонажа (VRM)»; их можно скачать в JSON. Для воспроизведения анимации предмета/камеры нужен соответствующий объект. Мимика, PPtr/MonoBehaviour-каналы, события и прочие поля импортированы, но VRM-плеер не исполняет скрипты игры, AnimatorController transitions, IK/контакты партнёров и движения сцены. Выражение лица и взаимодействие с мебелью поэтому могут отличаться от игры. Это библиотека исходных клипов с VRM-просмотром, формат VRMA не создавался.

Проверки: весь каталог сопоставлен с инвентаризацией; для каждого payload проверены распаковка, размеры массивов, streamed frames/индексы каналов, число channels/bindings. Семь idle-клипов сверены с прежним экспортом:93562сравнения, максимальная ошибка quaternion-компоненты около5.1e-8. На Mira проверены загрузка native-клипа,30строк/страница и отсутствие JS/NaN ошибок; на Rin проверено сидячее движение со сменой костюма и сохранением таймлайна. Не все игровые сцены были визуально воспроизведены.

Повторная сборка payload из `sources/` требует Python с UnityPy и orjson. Инвентаризация и скрипты лежат в `tools/animation-library/`; importer поддерживает переменные SHARD/SHARDS (по умолчанию один процесс). Для обновления каталога после параллельного импорта используется catalog.py. Анимационные скрипты работают внутри этого пакета; исторические QA-сценарии из рабочего каталога в пакет не включены.

Графы AnimatorController и связи сцен извлечены дополнительно в `../animation-links/`. Отдельная панель вьювера воспроизводит поддержанную часть переходов и связок слоёв; режим отдельных клипов этой библиотеки продолжает работать независимо. Ограничения — `../animation-links/README_RU.md`.

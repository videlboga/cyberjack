Здесь находятся двенадцать актуальных аутфитов, рабочие сравнительные варианты Rin, Blender-файлы, исходные экспорты, конвертеры, отчёты, превью и самостоятельная копия вьювера. ## Самостоятельный вьювер

Запустить из этого каталога:

```bash
./start-viewer.sh --port 8766
```

Открыть:

- [Rin](http://127.0.0.1:8766/vrm_view.html?vrm=models/x20/outfits/Rin_outfit_00.vrm)
- [Mira](http://127.0.0.1:8766/vrm_view.html?vrm=models/x20/mira/Mira_outfit_00.vrm)

Внутри `viewer/` находятся текущие HTML/JS/CSS, библиотека движений, Three.js, three-vrm и все модели. CDN и старый каталог control-room для запуска этой копии не нужны. Модели в `viewer/models/` связаны жёсткими ссылками только с файлами внутри этого же каталога; зависимости на старые рабочие директории отсутствуют. Остановить сервер: Ctrl+C.

## Исходники и инструменты

- `inputs/exports/`: четыре полных PMX-экспорта — первый Rin, Rin с четырьмя аутфитами, Mira и Kai. Сохранены PNG-карточки, текстуры и JSON физики/материалов.
- `inputs/blender/`: исходные KKBP-проекты. Mira сохраняет исходное техническое имя KamiwataKrista в части внутренних имён; отображаемое имя в VRM, файлах и интерфейсе — Mira.
- `inputs/animation/`: использованные Unity-бандлы рига и движений.
- `tools/blender-addons/`: копии реально использованных KKBP, VRM Add-on и mmd_tools. Версии — `tools/runtime_versions.json`.
- `tools/animation/`: извлечение исходных idle-движений и описание происхождения.
- `tools/qa/historical/`: исходные диагностические и тестовые сценарии. У них сохранены исторические абсолютные пути; для повторного запуска их нужно адаптировать.
- `tools/gltf-validator/`: локальная копия валидатора.
- `reports/`: общие отчёты, скриншоты и диагностика. Первоначальная гипотеза о коллайдерах как единственной причине проблемы юбки не доказана: существенную роль играл прежний вьювер.

Основные конвертеры в `characters/` перенастроены на пути внутри данного каталога. Для повторной конвертации используются Blender5.2.1, рабочие аддоны, Pillow и NumPy в его Python. Примеры из корня каталога:

```bash
/usr/bin/blender -b --python characters/mira/convert_mira.py
/usr/bin/blender -b --python characters/rin/outfits/convert_four_outfits.py
python3 characters/rin/outfits/finish_skirt_physics.py
/usr/bin/blender -b --python characters/rin/outfits/sync_four_outfit_skirt.py
```

Конвертеры записывают результаты рядом со скриптами, поэтому при повторном запуске заменят соответствующие собранные результаты. Скрипты восстановления промежуточных версий сохранены для диагностики; основные конвертеры уже содержат исправления Basis, видимости одежды и масок. Blender исходники также можно открыть непосредственно, без повторного импорта.

## Проверки и ограничения

Все двенадцать актуальных VRM прошли glTF validator с0 ошибок, текстуры встроены. Проверены переключение четырёх костюмов, сохранение позы/таймлайна и семь idle-поз; подробные JSON и превью лежат рядом с моделями. Полная библиотека Koikatsu: 56978 импортированных AnimationClip. Подробности, покрытие и ограничения переноса — в `animations/README_RU.md`.

DynamicBone перенесён в SpringBone приближённо. У Mira исходник не содержит физики платья. У Rin00 полные цепочки юбки и коллайдеры ног настроены отдельно. В Mira восстановлена T-поза из исходника, экспортированного с согнутыми руками и ногами, с согласованным преобразованием геометрии, морфов, нормалей и рига.

Состав и исходные расположения: `COPIED_FROM.json`. Контрольные суммы всех файлов: `SHA256SUMS.json`. Проверка целостности:

```bash
python3 tools/verify_bundle.py
```

Проверка собранного каталога: локальная копия вьювера загрузила Mira с138 привязанными костями, без JavaScript-ошибок и без запросов за пределы каталога; результат — reports/bundle_viewer_qa.json. Проверены заголовки всех16 VRM и встроенность их текстур. Синтаксис основных Python-конвертеров и JS вьювера проверен.

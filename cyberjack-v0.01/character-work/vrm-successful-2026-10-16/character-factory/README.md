## Как этим пользоваться

1. Референс → `character-spec.json` (антропометрия, черты лица, палитра).
2. По `keys-body.json` подобрать веса: каждому полю спеки соответствует ключ и его «цена» в мм,
   то есть можно считать ошибку в сантиметрах, а не «на глаз».
3. По `keys-face.json` — черты лица; `dead: true` исключать из подбора.
4. Проверка: рендер 3 ракурса + метрики силуэта против референса.

## Управляемые ключи, которые сначала считались мёртвыми

- **`VaginaOpen` (24.6 мм) и `AnusOpen` (18.8 мм)** — данные целые, но значение держит драйвер
  `var-1` от **костей `VaginaOpen` / `AnusOpen` на `rig_E`**. Штатное управление: `pose.bones['VaginaOpen'].scale.x = 2`
  даёт значение ключа 1.0. Оба можно включать одновременно.
  Проверено рендером: `keys/genital/sheet.png` (база · VaginaOpen · AnusOpen · оба, два ракурса), 39 515 пикселей разницы.
- **`Voluptuous` (40.4 мм)** — лежит с `mute = True`, включается флагом.

## Ограничения, которые уже проверены

- Шейпкеи меняют форму, но **не длину костей**: «длиннее ноги» так не сделать, нужно либо менять
  скелет (и ретаргетить клипы), либо держать пропорции в пределах ±5 %.
- В сцене **пять копий тела** (`Foot shape-1…5`) с одинаковым набором ключей — это варианты
  одежды/тела, при генерации персонажа нужно выбирать одну.
- Волосы (`Hair`, 2 773 вершины) и одежда — не параметрика, это библиотека ассетов.

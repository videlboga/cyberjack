# Управление размером груди (проверено замерами)

## Что реально управляет

| инструмент | диапазон | эффект (выступ вперёд, мм) | качество |
|---|---|---|---|
| **кости `Breast.L/R`, `Breast_0.L/R`** (масштаб) | 0.5 … 1.5 | −113 … −217 (глубина 175 → 278 мм) | чисто, отрывов нет даже на 1.5 |
| `BreastsSize` | 0 … 1 (отрицательные не работают) | 0 … +46 | ок |
| `BreastsImplants` | 0 … 1 | 0 … +41 | ок |
| `BreastsCleavage` | 0 … 1 | 0 … +34 | ок |
| `BreastsDiameter` | 0 … 1 | +20 | ок |
| `BreastShape08` | −1 … +1 (**инвертирован**) | −1 даёт +36, +1 почти 0 | ок |
| `B` | −1 … 1 | 137.9 мм по всему телу | глобальный тип фигуры |

Выводы:
1. **Уменьшить грудь ниже базовой шейпкеями нельзя**: `BreastsSize = −1` даёт 0 изменений.
   Уменьшение — только масштабом костей груди (0.5 даёт почти плоскую).
2. **Увеличивать** можно и костями, и ключами; ключи дают форму (импланты, сближение, диаметр).
3. Кости — единственный способ, который анимируется и работает независимо от остальных параметров тела.

## Методическая ошибка, которую важно не повторять

Уровень груди — **76–92 % высоты** от стоп (у модели 1.44 м это 1.09–1.32 м).
Я сначала мерил полосу 62–78 % — это живот и талия, поэтому все ключи груди выглядели
«без эффекта» (0.000). Меряется по вершинам в полосе 0.76–0.92 H с ограничением |x| ≤ 130 мм,
иначе в замер попадают руки.

## Как задавать персонажа

```
bust_scale 0.5 … 1.5     # кости груди: главный размер
bust_shape: {BreastsSize, BreastsImplants, BreastsCleavage, BreastsDiameter, BreastShape08}
body_type:  B (−1 … 1)   # общая полнота, влияет и на грудь
```

Пример: Мира — скромная грудь → `bust_scale 0.85`, ключи формы 0.

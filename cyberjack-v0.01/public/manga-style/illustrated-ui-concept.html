Что меняется:
1. Метрики — progress bars → акварельные измерители со штриховкой и чернильными рисками
2. Графики — SVG line charts → hand-drawn линии (turbulence filter) с акварельной заливкой
3. Пульс/осциллоскоп — digital waveforms → hand-drawn traces на бумажной сетке
4. Выносливость — CSS bars → вертикальные чернильные шкалы
5. Карта зон — button grid → карточки с мини-иконками и sens-барами (слоты под иллюстрации)
6. Станции — SVG rings → чернильная карта с секторами
7. Протокол — list → раскадровка со стрелками
8. Чат — plain text → манга-облака диалогов с портретами
9. Телеметрия — flat readout → записи в журнале с чернильными полосами
10. Кнопки — flat CSS → с double-border и soft shadow
11. Панели — flat backgrounds → manga-фреймы с уголками
12. Шрифт — monospace → Georgia/serif (более книжный, рисованый)

Что НЕ меняется:
— Иллюстрированные кнопки действий (78 PNG) — основа, сохраняются как есть
— Портреты, rendered-сцены, sex-machine, инфузии — все иллюстрации остаются
— Логика, API, движок — только presentation layer

Палитра (из анализа иллюстраций):
— Фон: тёплая бумага #f2ede8 (соответствует avg brightness 192 у action tiles)
— Чернила: #3a3530 (соответствует lineart #4e4f58 у портретов)
— Акценты: warm #c4a87a, cool #8aa89a, rose #c4a0a0, violet #9a92a8
— Насыщенность: ~25-31% (низкая, как в иллюстрациях)

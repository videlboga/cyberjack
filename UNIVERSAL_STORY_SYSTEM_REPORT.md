## Архитектурные решения

### 1. Универсальность
- **Единая система** для всех типов событий вместо отдельных модулей
- **Расширяемые типы** с возможностью добавления новых категорий
- **Переиспользуемые компоненты** для разных типов контента

### 2. Визуальный редактор
- **React Flow** для интуитивного создания сюжетов
- **Кастомные узлы** с уникальными иконками и цветами
- **Интерактивные панели** для редактирования свойств

### 3. Шаблонная система
- **Готовые решения** для быстрого старта
- **Кастомизация** существующих шаблонов
- **Организация** по типам и тегам

### 4. Интеграция
- **Связывание** сюжетов с игровыми событиями
- **Автоматические триггеры** на основе условий
- **Синхронизация** с существующими системами

## Преимущества новой системы

### 1. Упрощение разработки
- **Один инструмент** вместо множества специализированных
- **Единообразный интерфейс** для всех типов контента
- **Быстрое создание** через шаблоны

### 2. Гибкость

- **Кастомизация** под конкретные нужды
- **Масштабируемость** системы

### 3. Производительность
- **Оптимизированные** компоненты
- **Кэширование** ресурсов
- **Эффективная** обработка данных

### 4. Пользовательский опыт
- **Интуитивный интерфейс** с визуальным редактором
- **Быстрый доступ** к шаблонам
- **Понятная навигация** между элементами

## Миграция с старых систем

### Упраздненные разделы
- **Активности** → интегрированы в сюжетный редактор (типы: training, therapy)
- **Заказы** → интегрированы в сюжетный редактор (тип: contract)
- **Аномалии** → интегрированы в сюжетный редактор (тип: anomaly)

### Сохраненные разделы
- **Рынок** (бывший "Аукцион") - переименован для ясности
- **Сюжетный редактор** - расширен универсальными возможностями

## Готовые шаблоны

### 1. Корпоративный аукцион
- Тип: auction
- Триггеры: репутация рынка >= 50
- Экраны: вход, торги, результат

### 2. Аномалия в Void
- Тип: anomaly
- Триггеры: опыт в Void >= 1
- Экраны: обнаружение, исследование, результат

### 3. Корпоративный контракт
- Тип: contract
- Триггеры: корпоративные связи >= 5
- Экраны: встреча, переговоры, подписание

### 4. Спасательная операция в Void
- Тип: void_rescue
- Триггеры: опыт в Void >= 0
- Экраны: приближение, операция, результат

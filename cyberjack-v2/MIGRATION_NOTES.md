# CyberJack v2.0 - Заметки о миграции

## 🚨 КРИТИЧЕСКИ ВАЖНО

**CyberJack v2.0 - это НОВЫЙ проект, написанный с нуля!**

Этот проект НЕ является рефакторингом или обновлением оригинального CyberJack. Это полностью новая реализация, которая имеет только концептуальную связь с оригиналом.

## 🔄 Что изменилось кардинально

### Архитектура:
- **Было**: Монолитная структура с MongoDB
- **Стало**: Модульная архитектура с SQLite + Prisma

### Технологии:
- **Было**: Старые версии React, MongoDB, сложная структура
- **Стало**: Next.js 15, React 19, TypeScript, современный стек

### Система ИИ:
- **Было**: Одна модель для всего
- **Стало**: Две специализированные модели (DeepSeek + Gemini)

### Интерфейсы:
- **Было**: Сложная структура с множеством файлов
- **Стало**: Три четких раздела (БД, Админ, Игра)

## 📊 Сравнение систем

| Компонент | CyberJack v1 | CyberJack v2 |
|-----------|--------------|--------------|
| **Frontend** | Старый React | Next.js 15 + React 19 |
| **Database** | MongoDB | SQLite + Prisma |
| **AI** | Одна модель | Две специализированные |
| **Архитектура** | Монолитная | Модульная |
| **Типизация** | Частичная | Полная TypeScript |
| **Тестирование** | Минимальное | Полное покрытие |
| **Документация** | Базовая | Детальная |

## 🔧 Миграция данных

**ВНИМАНИЕ**: Данные из v1 НЕ совместимы с v2!

Если нужно перенести данные:
1. Экспортируйте данные из v1 в JSON
2. Создайте скрипт миграции для v2
3. Адаптируйте структуру данных под новую схему

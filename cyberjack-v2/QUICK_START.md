# ⚡ CyberJack v2.0 - Быстрый старт

## 🚀 ЗАПУСК (ОБЯЗАТЕЛЬНО!)

```bash
npm run restart
```

**НИКОГДА не используй `npm run dev`!**

## 🌐 АДРЕСА

- **Главная**: http://localhost:3000
- **Админ-панель**: http://localhost:3000/admin
- **Игра**: http://localhost:3000/game
- **База данных**: http://localhost:3000/db

## 📋 ПРАВИЛА

### ✅ ВСЕГДА:
- `npm run restart` для перезапуска
- Читай спецификацию перед изменениями
- Проверяй соответствие архитектуре

### ❌ НИКОГДА:
- `npm run dev` напрямую
- Хардкодь решения
- Игнорируй спецификацию

## 🔧 КОМАНДЫ

```bash
npm run restart          # Перезапуск (ОБЯЗАТЕЛЬНО!)
npm run db:push          # Синхронизация БД

npx tsc --noEmit         # Проверка TypeScript
```

# 🧮 Руководство по системе формул поз

## 📋 Обзор

Система формул поз позволяет создавать сложные условия активации, эффекты и модификаторы для поз персонажей. Это первая часть реализации системы поз согласно техническому плану.

## 🎯 Что реализовано

### ✅ **ЭТАП 1: Визуальный редактор формул для поз**
- **Интерфейсы и типы** - Полная типизация для условий, эффектов и модификаторов
- **Редактор формул** - Модальное окно с вкладками для разных типов формул
- **Готовые шаблоны** - Предустановленные формулы для быстрого создания
- **Валидация** - Проверка корректности формул в реальном времени

### ✅ **ЭТАП 2: API endpoints**
- `GET/PUT /api/poses/[id]/formulas` - Управление всеми формулами позы
- `GET/POST /api/poses/[id]/conditions` - Управление условиями
- `GET/POST /api/poses/[id]/effects` - Управление эффектами
- `GET/POST /api/poses/[id]/modifiers` - Управление модификаторами
- `POST/DELETE /api/poses/[id]/activate` - Активация/деактивация поз

### ✅ **ЭТАП 3: Система выполнения формул**
- **PoseFormulaSystem** - Основной класс для работы с формулами поз
- **Интеграция с FormulaEngine** - Использование существующей системы формул
- **Контекст выполнения** - Полный контекст с данными персонажа, пользователя и позы

## 🚀 Как использовать

### 1. **Доступ к редактору формул**
1. Перейдите в админ-панель → Позы
2. Найдите нужную позу
3. Нажмите кнопку 🧮 (Редактировать формулы)

### 2. **Создание условий**
Условия определяют, когда поза может быть активирована:

```typescript
// Примеры условий:
{
  type: 'characteristic',
  target: 'character.mood',
  operator: 'gte',
  value: 50,
  description: 'Настроение должно быть >= 50'
}

{
  type: 'equipment',
  target: 'user.equipment.rope',
  operator: 'gte',
  value: 1,
  description: 'Нужна веревка'
}
```

### 3. **Создание эффектов**
Эффекты применяются к характеристикам персонажа:

```typescript
// Примеры эффектов:
{
  type: 'characteristic',
  target: 'character.mood',
  formula: 'character.mood + 2',
  frequency: 'per_minute',
  description: 'Увеличивает настроение на 2 каждую минуту'
}

{
  type: 'characteristic',
  target: 'character.energy',
  formula: 'min(100, character.energy + (pose.duration * 0.5))',
  frequency: 'per_minute',
  description: 'Восстанавливает энергию с учетом времени в позе'
}
```

### 4. **Создание модификаторов**
Модификаторы влияют на действия в позе:

```typescript
// Примеры модификаторов:
{
  type: 'intensity',
  target: 'all',
  formula: 'action.intensity * 1.5',
  description: 'Увеличивает интенсивность всех действий на 50%'
}

{
  type: 'cost',
  target: 'all',
  formula: 'action.cost * 0.8',
  description: 'Уменьшает стоимость всех действий на 20%'
}
```

## 📊 Типы формул

### **Условия (Conditions)**
- `characteristic` - Условие по характеристике персонажа
- `equipment` - Условие по наличию оборудования
- `pose` - Условие по другой позе
- `time` - Условие по времени
- `custom` - Пользовательская формула

### **Эффекты (Effects)**
- `characteristic` - Влияние на характеристику
- `modifier` - Влияние на модификаторы
- `action` - Влияние на действия
- `custom` - Пользовательский эффект

### **Модификаторы (Modifiers)**
- `intensity` - Модификация интенсивности действий
- `cost` - Модификация стоимости действий
- `duration` - Модификация длительности действий
- `effect` - Модификация эффекта действий
- `success_rate` - Модификация шанса успеха

## 🔧 Операторы условий

- `eq` - Равно (==)
- `ne` - Не равно (!=)
- `gt` - Больше (>)
- `gte` - Больше или равно (>=)
- `lt` - Меньше (<)
- `lte` - Меньше или равно (<=)
- `in` - Входит в список
- `not_in` - Не входит в список

## ⏰ Частота эффектов

- `per_minute` - Каждую минуту игрового времени
- `per_hour` - Каждый час игрового времени
- `per_action` - При каждом действии
- `on_activation` - При активации позы
- `on_deactivation` - При деактивации позы

## 🎨 Готовые шаблоны

### **Условия:**
- **Условие по настроению** - `character.mood >= 50`
- **Условие по оборудованию** - `user.equipment.rope >= 1`

### **Эффекты:**
- **Эффект на настроение** - `character.mood + 2`
- **Эффект на энергию** - `min(100, character.energy + (pose.duration * 0.5))`

### **Модификаторы:**
- **Модификатор интенсивности** - `action.intensity * 1.5`
- **Модификатор стоимости** - `action.cost * 0.8`

Формулы имеют доступ к следующему контексту:

```typescript
{

    name: string,
    characteristics: Record<string, number>,

  },
  user: {
    id: string,
    name: string,
    modifiers: Record<string, number>,
    credits: number,

  },

    id: string,
    name: string,

    isActive: boolean
  },

```

## 🐛 Известные ограничения

1. **Нет интеграции с TimeSystem** - Эффекты не применяются автоматически
2. **Нет интеграции с ActionsSystem** - Модификаторы не учитываются
3. **Нет сохранения статуса поз** - Активные позы не сохраняются в БД
4. **Нет UI для активации поз** - Только API endpoints

## 📝 Примеры использования

### **Создание позы "Связанная"**
```typescript
// Условие: нужна веревка
{
  type: 'equipment',
  target: 'user.equipment.rope',
  operator: 'gte',
  value: 1
}

// Эффект: увеличивает покорность
{
  type: 'characteristic',
  target: 'character.submission',
  formula: 'character.submission + 1',
  frequency: 'per_minute'
}

// Модификатор: увеличивает интенсивность действий
{
  type: 'intensity',
  target: 'all',
  formula: 'action.intensity * 1.3'
}
```

### **Создание позы "Усталая"**
```typescript
// Условие: низкая энергия
{
  type: 'characteristic',
  target: 'character.energy',
  operator: 'lt',
  value: 30
}

// Эффект: медленно восстанавливает энергию
{
  type: 'characteristic',
  target: 'character.energy',
  formula: 'character.energy + 0.5',
  frequency: 'per_minute'
}

// Модификатор: уменьшает эффективность действий
{
  type: 'effect',
  target: 'all',
  formula: 'action.effect * 0.7'
}
```

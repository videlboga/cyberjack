## 🏗️ АРХИТЕКТУРА

### Основные системы:
1. **Система времени** - холд действий (1 сек = 1 мин игрового времени)
2. **Система характеристик** - 100-балльная с восстановлением
3. **Система действий** - с эффектами и требованиями
4. **Character AI** - OpenRouter API (GLM 4.5)
5. **Система раскрытия** - approximate/detailed/precise
6. **Система поз и анатомии** - с активными зонами

### Три основные страницы:
- **`/db`** - Интерфейс базы данных
- **`/admin`** - Админ-панель
- **`/game`** - Игровой интерфейс

## 🔧 ПОЛЕЗНЫЕ КОМАНДЫ

```bash
# Основные
npm run restart          # Чистый перезапуск (ОБЯЗАТЕЛЬНО!)
npm run dev:3000         # Запуск на порту 3000
npm run build            # Сборка проекта

# База данных
npm run db:generate      # Генерация Prisma клиента
npm run db:push          # Синхронизация схемы
npm run db:studio        # Prisma Studio

# Отладка
npx tsc --noEmit         # Проверка TypeScript
lsof -ti:3000 | xargs kill -9  # Освободить порт 3000
```

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Порт 3000 занят:
```bash

```

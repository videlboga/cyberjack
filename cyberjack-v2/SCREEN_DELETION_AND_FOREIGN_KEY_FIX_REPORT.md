# Отчет об исправлении ошибок удаления экрана и Foreign Key Constraint

## Проблемы

### 1. Ошибка удаления экрана
```
Ошибка удаления экрана: "{\"error\":\"Ошибка при удалении экрана\"}"
```
**Причина**: Экран уже был удален автоматически при удалении последнего выбора, но код пытался удалить его повторно.

### 2. Foreign Key Constraint при создании выбора
```
Foreign key constraint violated on the (not available)
```
**Причина**: При создании выбора ссылка на `nextScreenId` указывала на несуществующий экран.

## Анализ проблем

### 1. Логика удаления экрана
В админ-панели реализована следующая логика:
1. Удаляется выбор
2. Проверяется, остались ли у экрана выборы
3. Если выборов нет - экран автоматически удаляется
4. Но затем код пытается удалить экран повторно

### 2. Проблема с Foreign Key
При создании выбора в админ-панели:
1. Создается новый экран
2. Создается выбор, ссылающийся на этот экран
3. Но между этими операциями экран может быть удален или не существовать

## Исправления

### 1. Улучшение API удаления экрана

#### `/src/app/api/story/screens/[id]/route.ts`
Добавлена проверка существования экрана перед удалением:

```typescript
// Сначала проверяем, существует ли экран
const existingScreen = await prisma.screen.findUnique({
  where: { id }
})

if (!existingScreen) {
  console.log(`Экран ${id} уже удален или не существует`)
  return NextResponse.json({ success: true, message: 'Экран уже удален' })
}
```

**Преимущества**:
- ✅ Предотвращает ошибки при попытке удалить несуществующий экран
- ✅ Возвращает успешный результат, если экран уже удален
- ✅ Улучшена обработка ошибок с детальными сообщениями

### 2. Валидация Foreign Key при создании выбора

#### `/src/app/api/story/screens/[id]/choices/route.ts`
Добавлена проверка существования `nextScreenId`:

```typescript
// Проверяем, существует ли экран, к которому ссылается выбор
if (validatedData.nextScreenId) {
  const nextScreen = await prisma.screen.findUnique({
    where: { id: validatedData.nextScreenId }
  })

  if (!nextScreen) {
    return NextResponse.json(
      { error: 'Экран для перехода не найден', details: `Экран с ID ${validatedData.nextScreenId} не существует` },
      { status: 400 }
    )
  }
}
```

**Преимущества**:
- ✅ Предотвращает Foreign Key constraint violations
- ✅ Возвращает понятные сообщения об ошибках
- ✅ Валидирует данные перед сохранением в БД

### 3. Улучшение обработки ошибок в админ-панели

#### `components/admin/ScreenBasedStoryAdmin.tsx`
Добавлена умная обработка ошибок удаления экрана:

```typescript
// Не показываем ошибку пользователю, если экран уже удален
try {
  const errorData = JSON.parse(errorText)
  if (errorData.message && errorData.message.includes('уже удален')) {
    console.log('Экран уже был удален, это нормально')
    return
  }
} catch {
  // Если не удалось распарсить JSON, показываем ошибку
}
alert('Ошибка удаления экрана: ' + errorText)
```

**Преимущества**:
- ✅ Не показывает ложные ошибки пользователю
- ✅ Логирует нормальные случаи в консоль
- ✅ Показывает реальные ошибки через alert

# CyberJack v2.0 - Полностью новая архитектура

## 🚨 ВАЖНО: Это НОВЫЙ проект с нуля

**CyberJack v2.0** - это полностью переписанная с нуля версия оригинального CyberJack. Этот проект имеет только **концептуальную связь** с оригиналом и представляет собой совершенно новую архитектуру и реализацию.

### 🔄 Отличия от оригинального CyberJack:

- **Новая архитектура**: Next.js 15 + React 19 + TypeScript
- **Новая база данных**: SQLite с Prisma ORM (вместо MongoDB)
- **Новая система ИИ**: OpenRouter API с двумя моделями
- **Новая структура**: Модульная архитектура с четким разделением
- **Новые интерфейсы**: Три основных раздела (БД, Админ, Игра)
- **Новая система характеристик**: 100-балльная система с восстановлением
- **Новая система времени**: Холд действий с ускорением времени

## 🏗️ Архитектура

### Технологический стек:
- **Frontend**: Next.js 15, React 19, TypeScript
- **Database**: SQLite с Prisma ORM
- **UI**: Tailwind CSS, Radix UI
- **AI**: OpenRouter API (DeepSeek + Gemini)
- **Authentication**: NextAuth.js (планируется)

### Структура проекта:
```
cyberjack-v2/
├── src/app/                    # Next.js App Router
│   ├── (auth)/                 # Защищенные маршруты
│   │   ├── db/                 # Интерфейс базы данных
│   │   ├── admin/              # Админ-панель
│   │   └── game/               # Игровой интерфейс
│   └── api/                    # API endpoints
├── lib/                        # Библиотеки и системы
│   ├── db/                     # База данных
│   ├── core/                   # Основные системы
│   └── character/              # Character AI
├── components/                 # UI компоненты
├── types/                      # TypeScript типы
└── hooks/                      # React хуки
```

## 🎮 Основные функции

### 1. Интерфейс базы данных (`/db`)
- Управление персонажами, пользователями, системными настройками
- Реальная статистика из базы данных
- CRUD операции для всех сущностей

### 2. Админ-панель (`/admin`)
- Управление характеристиками, действиями, позами
- Создание и настройка игровых элементов
- Полнофункциональные формы с валидацией

### 3. Игровой интерфейс (`/game`)
- Взаимодействие с персонажами
- Чат с ИИ (DeepSeek + Gemini)
- Система действий с эффектами
- Отображение характеристик в реальном времени

## 🚀 Быстрый старт

### ⚡ ОБЯЗАТЕЛЬНО: Используй скрипт перезапуска!
```bash
cd cyberjack-v2
npm run restart
```
**НИКОГДА не используй `npm run dev` напрямую!**

### Установка:
```bash
cd cyberjack-v2
npm install
```

### Настройка:
1. Скопируйте `.env.example` в `.env`
2. Настройте переменные окружения (особенно OpenRouter API ключи)
3. База данных синхронизируется автоматически при запуске

### Запуск:
```bash
npm run restart  # Чистый перезапуск на порту 3000
```

### Проверка работы:
- Главная: http://localhost:3000
- Админ-панель: http://localhost:3000/admin
- Игра: http://localhost:3000/game
- База данных: http://localhost:3000/db

### Заполнение тестовыми данными:
```bash
npm run db:seed
```

## 🔧 API

### Основные endpoints:
- `GET /api/characters` - Список персонажей
- `POST /api/characters` - Создание персонажа
- `GET /api/characteristics` - Список характеристик
- `POST /api/chat/[characterId]` - Чат с ИИ

### Тестирование API:
```bash
npx tsx scripts/test-all-functionality.ts
```

## 📊 Системы

### Character AI:
- **Основная модель**: DeepSeek Chat v3 (генерация ответов)
- **Анализ сообщений**: Gemini 2.5 Flash Lite
- **Контекст**: Характеристики, действия, память персонажа

### Система характеристик:
- 100-балльная шкала (0-100)
- Автоматическое восстановление к базовым значениям
- Сдвиг базовых значений при длительном изменении
- Система раскрытия знаний

### Система времени:
- 1 секунда реального времени = 1 минута игрового времени (при холде)
- Ручное управление временем
- Автоматическое восстановление характеристик

# Отчет об исправлении системных сообщений в чате

## 🎯 Проблема

Пользователь сообщил, что системные сообщения о действиях отображаются в чате:

```
"К тебе было применено действие "Погладить" к Лицо (90-й раз). Это вызвало: Энергия изменилась на -0.3, Настроение изменилась на +0.2. Как ты реагируешь на это действие?"
```

Эти сообщения должны отправляться "тихо" для ИИ, но пользователь должен видеть только ответ персонажа.

## 🔍 Анализ проблемы

### Причина:
- Системные сообщения о действиях сохранялись в чат как обычные сообщения пользователя
- Фильтрация системных сообщений отсутствовала
- Пользователь видел техническую информацию вместо естественного диалога

### Влияние:
- Нарушение иммерсивности игры
- Показ технических деталей пользователю
- Неестественный вид чата

## 🛠️ Реализованное решение

### 1. Добавлена фильтрация системных сообщений

**Файл:** `lib/character/ai-service.ts`

#### Обновлен метод `saveResponseToChat`:
```typescript
// Проверяем, является ли сообщение системным (о действии)
const isSystemMessage = userMessage.includes('К тебе было применено действие') ||
                        userMessage.includes('Это вызвало:') ||
                        userMessage.includes('Как ты реагируешь на это действие?')

// Сохраняем сообщение пользователя только если это НЕ системное сообщение
if (!isSystemMessage) {
  await prisma.chatMessage.create({
    data: {
      content: userMessage,
      senderId: userId,
      characterId,
      messageType: 'user',
      emotionalTone: 'neutral'
    }
  })
}
```

### 2. Создан API endpoint для очистки

**Файл:** `src/app/api/chat/[characterId]/clear-system/route.ts`

- Удаляет системные сообщения из чата
- Возвращает количество удаленных сообщений

## 📋 Логика работы системы

### 1. ИИ-триггеры при действиях
1. **Пользователь выполняет действие** (клик на зону персонажа)
2. **Система проверяет триггеры** (2-е, 10-е, 20-е применение)
3. **При срабатывании триггера** создается системное сообщение
4. **AI генерирует ответ** на системное сообщение
5. **Системное сообщение НЕ сохраняется** в чат (фильтруется)
6. **Ответ ИИ сохраняется** в чат как реакция персонажа

### 2. Обычный диалог в чате
1. **Пользователь отправляет сообщение** через ChatPanel
2. **Сообщение сохраняется** в базу данных как `messageType: 'user'`
3. **AI сервис генерирует ответ** на основе контекста персонажа
4. **Ответ сохраняется** в базу данных как `messageType: 'character'`
5. **ChatPanel отображает** оба сообщения

### 3. Фильтрация системных сообщений
- **Проверка содержания** - поиск ключевых фраз
- **Пропуск сохранения** - системные сообщения не попадают в чат
- **Сохранение ответов** - ИИ-ответы всегда сохраняются

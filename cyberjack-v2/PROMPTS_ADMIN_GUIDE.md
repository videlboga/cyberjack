# 🎭 Руководство по управлению промптами ИИ-персонажей

## 📋 Обзор

Система управления промптами позволяет создавать и настраивать шаблоны промптов для ИИ-персонажей, а также управлять индивидуальными настройками промптов для каждого персонажа.

## 🏗️ Архитектура системы

### Компоненты системы:

1. **PromptTemplatesAdmin** - Управление глобальными шаблонами промптов
2. **CharacterPromptsManager** - Настройка промптов для конкретных персонажей
3. **API Endpoints** - Backend для работы с промптами
4. **PromptSystem** - Система построения и рендеринга промптов

## 🚀 Быстрый старт

### Доступ к системе промптов:

1. **Глобальные шаблоны**: `/admin/prompts`
2. **Промпты персонажа**: `/admin/characters` → выбрать персонажа → вкладка "Промпты"

## 📝 Управление шаблонами промптов

### Создание шаблона:

1. Перейдите в `/admin/prompts`
2. Нажмите "Создать шаблон"
3. Заполните поля:
   - **Название** - имя шаблона
   - **Описание** - краткое описание назначения
   - **Категория** - тип промпта (описание персонажа, характеристики, память и т.д.)
   - **Шаблон** - текст промпта с переменными `{{variableName}}`
   - **Переменные** - определение переменных для шаблона
   - **Приоритет** - порядок применения (0-100)
   - **Активен** - включен ли шаблон

### Категории промптов:

- **Описание персонажа** - базовое описание и характер
- **Характеристики** - отображение текущих характеристик
- **Память** - контекст воспоминаний
- **Контекст** - общий контекст
- **Стиль ответа** - правила ответа
- **Эмоции** - эмоциональное состояние
- **Ситуация** - текущая ситуация
- **Взаимодействие** - правила взаимодействия

### Переменные в шаблонах:

```handlebars
{{characterName}} - имя персонажа
{{characterDescription}} - описание персонажа
{{characteristics}} - массив характеристик
{{memory}} - объект с воспоминаниями
{{currentPose}} - текущая поза
{{userMessage}} - сообщение пользователя
```

### Условные блоки:

```handlebars
{{#if condition}}
  Контент, если условие истинно
{{/if}}
```

### Циклы:

```handlebars
{{#each array}}
  {{property}} - свойство элемента массива
{{/each}}
```

## 🎭 Настройка промптов персонажа

### Добавление промпта к персонажу:

1. Выберите персонажа в `/admin/characters`
2. Перейдите на вкладку "Промпты"
3. Нажмите "Добавить промпт"
4. Выберите шаблон из списка
5. Настройте параметры:
   - **Кастомный шаблон** - переопределение базового шаблона
   - **Приоритет** - порядок применения
   - **Активен** - включен ли промпт
   - **Переменные** - значения переменных

### Тестирование промптов:

1. Перейдите на вкладку "Тестирование"
2. Введите тестовое сообщение
3. Нажмите "Тестировать промпты"
4. Просмотрите сгенерированный промпт

### Обновление динамических промптов:

- Нажмите "Обновить динамические" для пересоздания промптов на основе текущего состояния персонажа

## 🔧 API Endpoints

### Шаблоны промптов:

- `GET /api/admin/prompt-templates` - получить все шаблоны
- `POST /api/admin/prompt-templates` - создать шаблон
- `GET /api/admin/prompt-templates/[id]` - получить шаблон
- `PUT /api/admin/prompt-templates/[id]` - обновить шаблон
- `DELETE /api/admin/prompt-templates/[id]` - удалить шаблон

### Промпты персонажей:

- `GET /api/admin/characters/[characterId]/prompts` - получить промпты персонажа
- `POST /api/admin/characters/[characterId]/prompts` - добавить промпт
- `PUT /api/admin/characters/[characterId]/prompts/[promptId]` - обновить промпт
- `DELETE /api/admin/characters/[characterId]/prompts/[promptId]` - удалить промпт
- `POST /api/admin/characters/[characterId]/test-prompt` - тестировать промпты
- `POST /api/admin/characters/[characterId]/refresh-prompts` - обновить динамические промпты

## 📊 Встроенные шаблоны

### 1. Описание персонажа
```handlebars
Ты - {{characterName}}, {{characterDescription}}

Твой характер: {{characterPersonality}}
Твой возраст: {{characterAge}}
Твоя внешность: {{characterAppearance}}

Ты находишься в игре, где тебя воспринимают как актив.
Помни об этом, но не упоминай это напрямую.
```

### 2. Отображение характеристик
```handlebars
Твои текущие характеристики:
{{#each characteristics}}
- {{name}} ({{category}}): {{currentValue}}/100
{{/each}}

Эти характеристики влияют на твое поведение и реакции.
```

### 3. Стиль ответа
```handlebars
Правила ответа:
- Отвечай как {{characterName}}, оставаясь в характере
- Будь естественным и эмоциональным
- Учитывай свои характеристики и текущее состояние
- Не упоминай, что ты в игре или ИИ
- Реагируй на эмоции и намерения пользователя
- Используй короткие, естественные фразы
- Избегай сценических ремарок
- Будь отзывчивым и живым

Сообщение пользователя: "{{userMessage}}"

Ответь как {{characterName}}:
```

## 🎯 Лучшие практики

### Создание эффективных промптов:

1. **Четкость** - используйте ясные и конкретные инструкции
2. **Контекст** - включайте релевантную информацию о персонаже
3. **Переменные** - используйте переменные для динамического контента
4. **Приоритеты** - правильно расставляйте приоритеты промптов
5. **Тестирование** - всегда тестируйте промпты перед использованием

### Структура промпта:

1. **Описание персонажа** (приоритет 100)
2. **Характеристики** (приоритет 90)
3. **Память и контекст** (приоритет 80)
4. **Текущая ситуация** (приоритет 70)
5. **Стиль ответа** (приоритет 60)
6. **Эмоциональный контекст** (приоритет 50)

### Переменные и их типы:

- **STRING** - текстовые значения
- **NUMBER** - числовые значения
- **BOOLEAN** - логические значения
- **ARRAY** - массивы данных
- **OBJECT** - объекты с вложенными свойствами

## 🔍 Отладка и мониторинг

### Предварительный просмотр:

- Используйте кнопку "👁️" для просмотра шаблона
- Проверяйте переменные и их значения
- Убедитесь в корректности синтаксиса

- Тестируйте с разными типами сообщений
- Проверяйте генерацию промптов в разных состояниях персонажа

### Мониторинг производительности:

- Следите за размером генерируемых промптов
- Оптимизируйте длинные шаблоны
- Используйте кэширование для часто используемых промптов

## 🚨 Устранение неполадок

### Частые проблемы:

1. **Промпт не применяется** - проверьте приоритет и активность
2. **Переменные не подставляются** - проверьте правильность имен переменных
3. **Ошибки в шаблоне** - проверьте синтаксис Handlebars
4. **Медленная генерация** - оптимизируйте сложные шаблоны

### Логи и отладка:

- Проверяйте консоль браузера на ошибки JavaScript
- Используйте Network tab для мониторинга API запросов
- Проверяйте логи сервера для backend ошибок

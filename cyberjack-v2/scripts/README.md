# Скрипты для работы с базой данных

## 🌱 Генерация тестовых данных

### Базовое заполнение
```bash
npm run db:seed
```
Создает минимальный набор данных для разработки (очищает базу данных):
- 1 администратор
- 3 базовые характеристики (Настроение, Энергия, Возбуждение)
- 2 анатомические зоны (Грудь, Гениталии)
- 2 позы (Стоя, Лежа)
- 2 действия (Нежные прикосновения, Интенсивные ласки)
- 1 тестовый персонаж

### Расширенное заполнение
```bash
npm run db:seed:full
```
Создает полный набор данных для тестирования (очищает базу данных):
- 2 пользователя (админ + тестовый)
- 12 характеристик (физические, эмоциональные, сексуальные, психологические)
- 12 анатомических зон (основные, дополнительные, чувствительные)
- 8 поз (основные, покорные, расслабленные)
- 16 ракурсов поз
- 9 активных зон
- 10 действий (ласки, команды, стимуляция, наказания)
- 4 персонажа с уникальными характеристиками
- 48 характеристик персонажей
- 48 анатомических записей
- 32 позы персонажей
- 8 копий персонажей для пользователей
- 56 записей знаний пользователей
- 5 сюжетных точек
- 4 сцены
- 3 сущности станции

## 🚀 Команды разработки

### Основные команды
```bash
npm run restart          # Чистый перезапуск (ОБЯЗАТЕЛЬНО!)
npm run dev:3000         # Запуск на порту 3000
npm run build            # Сборка проекта
```

### База данных
```bash
npm run db:generate      # Генерация Prisma клиента
npm run db:push          # Синхронизация схемы
npm run db:migrate       # Создание миграций
npm run db:seed          # Базовое заполнение
npm run db:seed:full     # Расширенное заполнение
npm run db:fix:characteristics  # Исправление характеристик
npm run db:studio        # Prisma Studio
```

## 🔧 Настройка

### Переменные окружения
Убедитесь, что в `.env` настроена база данных:
```env
DATABASE_URL="postgresql://username:password@localhost:5432/cyberjack_v2"
```

### Первый запуск
```bash
# 1. Установить зависимости
npm install

# 2. Сгенерировать Prisma клиент
npm run db:generate

# 3. Создать базу данных
npm run db:push

# 4. Заполнить тестовыми данными
npm run db:seed:full

# 5. Запустить проект
npm run restart
```

## 🔧 Исправление характеристик

### Система характеристик
- Все определения характеристик автоматически применяются ко всем персонажам
- При создании новой характеристики она добавляется всем активным персонажам
- При создании нового персонажа он получает все активные характеристики
- При удалении определения характеристики она каскадно удаляется у всех персонажей

### Команда исправления
```bash
npm run db:fix:characteristics
```
- Удаляет дублирующиеся определения характеристик
- Синхронизирует характеристики для всех персонажей
- Показывает статистику по характеристикам

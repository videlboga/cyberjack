# Отчет об исправлении логики удаления экранов

## Проблема

При удалении выбора в админ-панели удалялся неправильный экран:
- **Удалялся**: Экран, на котором был выбор (screenId)
- **Должен удаляться**: Экран, на который ведет выбор (nextScreenId)

## Анализ проблемы

### Неправильная логика в API endpoint
В `/src/app/api/story/choices/[id]/route.ts` была следующая логика:

```typescript
// НЕПРАВИЛЬНО: Удалялся экран с выбором
const screenId = existingChoice.screenId
if (remainingChoices.length === 0) {
  await prisma.screen.delete({
    where: { id: screenId }  // ❌ Удалялся экран с выбором
  })
}
```

### Правильная логика
Должна быть:

```typescript
// ПРАВИЛЬНО: Удаляется экран, на который ведет выбор
const nextScreenId = existingChoice.nextScreenId
if (nextScreenId) {
  await prisma.screen.delete({
    where: { id: nextScreenId }  // ✅ Удаляется целевой экран
  })
}
```

## Исправления

### 1. Исправление API endpoint удаления выбора

#### `/src/app/api/story/choices/[id]/route.ts`

**Было:**
```typescript
// Проверяем, остались ли у экрана выборы
const remainingChoices = await prisma.choice.findMany({
  where: { screenId }
})

// Если у экрана больше нет выборов, удаляем его
if (remainingChoices.length === 0) {
  await prisma.screen.delete({
    where: { id: screenId }  // ❌ Неправильно
  })
}
```

**Стало:**
```typescript
// Если у выбора есть связанный экран (nextScreen), удаляем его
if (nextScreenId) {
  console.log(`Удаляем экран, на который вел выбор: ${nextScreenId}`)

  // Проверяем, существует ли целевой экран
  const targetScreen = await prisma.screen.findUnique({
    where: { id: nextScreenId }
  })

  if (targetScreen) {
    await prisma.screen.delete({
      where: { id: nextScreenId }  // ✅ Правильно
    })
    console.log(`Экран ${nextScreenId} удален`)
  } else {
    console.log(`Экран ${nextScreenId} уже удален или не существует`)
  }
} else {
  console.log('У выбора нет связанного экрана для удаления')
}
```

### 2. Упрощение логики в админ-панели

#### `components/admin/ScreenBasedStoryAdmin.tsx`

**Было:**
```typescript
// Находим удаляемый выбор, чтобы получить nextScreenId
const deletedChoice = screenWithChoice.choices.find(choice => choice.id === choiceId)

if (deletedChoice && deletedChoice.nextScreenId) {
  console.log(`Удаляем экран, на который вел выбор: ${deletedChoice.nextScreenId}`)
  await handleDeleteScreen(deletedChoice.nextScreenId)
} else {
  console.log('У выбора нет связанного экрана для удаления')
}
```

**Стало:**
```typescript
// API endpoint теперь сам обрабатывает удаление целевого экрана
console.log('Выбор удален, API обработает удаление связанного экрана')
```

# Руководство по расширенной системе ИИ-персонажей

## 🚀 Обзор улучшений

Система взаимодействия с ИИ-персонажами была значительно расширена для более глубокой интеграции с игровыми механиками:

### ✨ Новые возможности:

1. **Расширенный анализ сообщений** - связь с характеристиками и позами
2. **Детекция команд поз** - понимание команд принятия поз
3. **Влияние на характеристики** - изменение настроения и фетишей от сообщений
4. **Система действий-сообщений** - автоматические реакции на действия
5. **Отслеживание реакций** - полная история взаимодействий

## ⚡ Система действий-сообщений

### Принцип работы:

1. **Регистрация действий** - каждое выполненное действие регистрируется
2. **Накопление** - действия накапливаются до достижения порога
3. **Автоматическая отправка** - ИИ получает сообщение о действиях
4. **Реакция персонажа** - персонаж реагирует на действия

### Конфигурация:

```typescript
interface ActionMessageConfig {
  messageThreshold: number    // Порог действий (по умолчанию: 3)
  timeThreshold: number      // Временной порог в секундах (по умолчанию: 30)
  enableAutoMessages: boolean // Включить автосообщения
  messageTemplates: ActionMessageTemplate[] // Шаблоны сообщений
}
```

### Шаблоны сообщений:

#### **Общие действия**
```
Выполнено {{actionCount}} действий: {{allActions}}.
Средняя интенсивность: {{avgIntensity}}%.
```

#### **Высокая интенсивность**
```
Выполнено интенсивное действие "{{lastAction}}"
с силой {{avgIntensity}}%.
```

#### **Действия нежности**
```
Проявлена нежность: {{allActions}}.
Время: {{timeSpan}}.
```

#### **Действия наказания**
```
Применено наказание: {{lastAction}}
с интенсивностью {{avgIntensity}}%.
```

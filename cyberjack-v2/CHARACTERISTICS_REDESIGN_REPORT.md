### 3. API валидации формул
Создан новый API endpoint `/api/formulas/validate`:

#### GET `/api/formulas/validate`
Возвращает список всех доступных переменных для формул:
- Характеристики персонажа (49 штук)
- Параметры действия (intensity, duration, category)
- Параметры пользователя (modifiers, credits)
- Параметры зоны (sensitivity, coordinates)
- Системные параметры (gameTime, realTime, isActionHolding)

#### POST `/api/formulas/validate`
Валидирует формулу и проверяет:
- Синтаксис формулы
- Типы данных
- Существование переменных
- Семантическую корректность

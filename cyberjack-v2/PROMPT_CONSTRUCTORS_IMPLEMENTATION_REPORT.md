Успешно реализована система конструкторов промптов для динамического создания контекстных промптов на основе характеристик персонажей, их поз и активных зон.

## 📋 Выполненные задачи

### ✅ 1. Конструктор промптов на основе характеристик
- **Файл:** `lib/character/prompt-constructors.ts`
- **Описание:** Система анализа характеристик и генерации промптов
- **Возможности:**
  - Анализ доминирующих, экстремальных и низких характеристик
  - Группировка по категориям
  - Вычисление общей статистики (среднее, разброс, волатильность)
  - 4 контекста: high, low, extreme, normal
  - Динамические описания характеристик

### ✅ 2. Конструктор промптов на основе поз
- **Описание:** Система анализа поз и активных зон
- **Возможности:**
  - Анализ типа позы (intimate, exposed, restrained, neutral)
  - Определение интенсивности (0-10)
  - Выявление чувствительных и открытых областей
  - Анализ активных зон и анатомии
  - Контекстные инструкции по поведению

### ✅ 3. Комбинированный конструктор
- **Описание:** Объединение анализа характеристик и поз
- **Возможности:**
  - 4 контекста взаимодействия: interaction, action, emotion, general
  - Интеграция всех аспектов состояния персонажа
  - Комплексные инструкции по поведению
  - Адаптивные промпты под ситуацию

### ✅ 4. Интеграция с основной системой
- **Файл:** `lib/character/prompt-system.ts`
- **Описание:** Интеграция конструкторов с PromptSystem
- **Возможности:**
  - Автоматическое создание динамических промптов
  - Управление жизненным циклом промптов
  - Валидация и оптимизация
  - Кэширование и обновление

### ✅ 5. Обновление AI сервиса
- **Файл:** `lib/character/ai-service.ts`
- **Описание:** Интеграция с основным AI сервисом
- **Возможности:**
  - Автоматическое создание промптов при генерации ответов
  - Анализ характеристик для определения контекста
  - Динамическое обновление промптов
  - Fallback стратегии

### ✅ 6. Тестирование системы

### Создание промпта на основе характеристик

```typescript
  characterId,
  'high' // контекст для высоких характеристик
)

// Результат:
// "Твои характеристики влияют на твое поведение:
//  Доминирующие черты (высокие значения):
//  - чувствительность: 85/100 - очень чувствителен к прикосновениям
//  Общее состояние: очень возбужден и активен
//  Твои высокие характеристики делают тебя очень отзывчивым..."
```

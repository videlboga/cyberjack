## 🚀 Новые возможности

### 📊 **Сюжетные точки**
- **3 типа**: Число, Да/Нет, Текст
- **5 категорий**: Отношения, Навыки, Ресурсы, Сюжет, Другое
- **Примеры использования** для каждого типа
- **Визуальные индикаторы** прогресса и состояния

### ⚡ **Условия**
- **5 типов условий**: Равно, Больше, Меньше, Диапазон, Содержит
- **Связь с сюжетными точками**
- **Валидация и проверки**
- **Примеры и шаблоны**

### 🎯 **Триггеры**
- **Автоматические события** на основе условий
- **Система действий** (диалоги, разблокировка сцен)
- **Управление активностью**
- **Интеграция с игровыми механиками**

## 🎮 Практические примеры

### Создание системы репутации:
```json
{
  "market_reputation": {
    "name": "Репутация на рынке",
    "type": "numeric",
    "category": "story",
    "value": 0,
    "minValue": 0,
    "maxValue": 100,
    "tags": ["market", "reputation"]
  }
}
```

### Условие для высокой репутации:
```json
{
  "high_reputation": {
    "name": "Высокая репутация",
    "description": "Репутация на рынке выше 50",
    "storyPointId": "market_reputation",
    "type": "greater",
    "value": 50
  }
}
```

### Триггер для автоматического аукциона:
```json
{
  "auto_auction": {
    "name": "Автоматический аукцион",
    "description": "Запускает корпоративный аукцион при высокой репутации",
    "conditionIds": ["high_reputation"],
    "actions": [
      {
        "type": "showDialog",
        "target": "corporate_auction_invitation",
        "value": "Вас приглашают на корпоративный аукцион!"
      }
    ],
    "isActive": true
  }
}
```

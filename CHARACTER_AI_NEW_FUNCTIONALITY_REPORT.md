# 🎭 Character AI - Новая функциональность

## 🎯 Что реализовано

### 1. Чат с персонажем 💬
- **Плавающая панель чата** с возможностью перетаскивания
- **Анализ сообщений** на наличие команд и действий
- **Автоматическое выполнение действий** при обнаружении ключевых слов
- **Ответы персонажа** на основе выполненных действий
- **Индикация действий** в сообщениях

### 2. Палитра действий и инструментов 🎮
- **Все действия доступны** (без кулдаунов и ограничений)
- **Новая конфигурация** с нужными действиями:
  - Ударить (рука, плеть)
  - Погладить (рука, перчатка)
  - Щекотать (щётка, перо)
  - Лизнуть
  - Вставить член
- **Инструменты** с настройкой интенсивности:
  - Шокер (с настройкой мощности)

### 3. Система поз 🦵
- **Смена поз через панель**:
  - Поставить на ноги
  - Поставить на колени
  - Поставить на четвереньки
  - Положить на спину
- **Смена поз через чат** (через ключевые слова)

### Компоненты

#### CharacterChat.tsx
- Плавающая панель чата
- Анализ сообщений на ключевые слова
- Автоматическое выполнение действий
- Генерация ответов персонажа
- Индикация выполненных действий

#### ActionToolPanel.tsx (обновлен)
- Вкладка "Действия" - все доступные действия
- Вкладка "Инструменты" - шокер с настройкой мощности
- Вкладка "Позы" - смена поз персонажа
- Все действия доступны без ограничений

## 🎮 Как использовать

### 1. Включение AI режима
- Нажмите кнопку "Личная работа" в верхней панели
- Откроется панель управления внизу экрана

### 2. Чат с персонажем
- Нажмите кнопку "💬 Чат с персонажем"
- Напишите сообщение с ключевыми словами:
  - "Ударить" → выполнится действие удара
  - "Погладить" → выполнится поглаживание
  - "Встать на колени" → смена позы
  - "Щекотать щёткой" → щекотание щёткой

### 3. Действия и инструменты
- Нажмите кнопку "🤖 Действия и инструменты"
- Выберите действие и настройте интенсивность
- Для инструментов (шокер) настройте мощность

### 4. Смена поз
- Через панель действий → вкладка "Позы"
- Через чат → "встать на колени", "лечь на спину" и т.д.

## 🔍 Ключевые слова для чата

### Действия:
- **Ударить**: "удар", "ударить", "шлепнуть", "побить"
- **Погладить**: "погладить", "ласкать", "нежно"
- **Щекотать**: "щекотать", "щекочу"
- **Лизнуть**: "лизать", "лизнуть", "облизать"
- **Вставить**: "вставить", "войти", "проникнуть"

### Позы:
- **Смена позы**: "встать", "лечь", "сесть", "колени", "четвереньки"

## ⚙️ Настройка инструментов

### Шокер
- **Базовая интенсивность**: 5
- **Максимальная интенсивность**: 10
- **Эффекты**: боль, страх, подчинение
- **Множители**: настраиваются в конфиге

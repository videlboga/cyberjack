## 🚀 Как использовать сюжетный редактор

### 1. **Доступ к редактору**
Перейдите по адресу: `http://localhost:3000/game/story-editor`

### 2. **Основные компоненты**

#### 📊 StoryPointsManager (Управление сюжетными точками)
- **Создание точек**: Нажмите "Добавить точку"
- **Редактирование**: Выберите точку и настройте параметры
- **Типы точек**:
  - `numeric` - числовые значения (репутация, навыки)
  - `boolean` - да/нет (статусы, флаги)
  - `string` - текстовые значения (имена, описания)

#### 🎨 StoryEditor (Визуальный редактор)
- **Создание сцен**: Перетаскивайте узлы на холст
- **Связи**: Соединяйте экраны стрелками
- **Типы узлов**:
  - 🏪 Market - рыночные события
  - ⚡ Anomaly - аномалии и опасности
  - 🏢 Corporate - корпоративные события
  - 🎮 Training - тренировочные события

#### 📋 StoryTemplates (Шаблоны)
- **Готовые шаблоны**: Выберите из списка
- **Кастомизация**: Настройте под свои нужды
- **Сохранение**: Создайте свои шаблоны

### 3. **Создание нового события**

#### Шаг 1: Выберите шаблон
```json
{
  "id": "corporate_auction",
  "title": "Корпоративный аукцион",
  "type": "auction",
  "category": "market"
}
```

#### Шаг 2: Настройте триггеры
```json
{
  "triggerConditions": [
    {
      "type": "story_point",
      "pointId": "market_reputation",
      "operator": ">=",
      "value": 50
    }
  ],
  "probability": 80
}
```

#### Шаг 3: Создайте экраны
```json
{
  "screens": [
    {
      "id": "auction_intro",
      "title": "Вход в аукционный зал",
      "description": "Описание сцены",
      "choices": [
        {
          "id": "observe",
          "text": "Наблюдать за участниками",
          "consequences": [
            { "type": "story_point_change", "pointId": "corporate_connections", "change": 1 }
          ]
        }
      ]
    }
  ]
}
```

### 4. **Система сюжетных точек**

#### Базовые точки:
- **market_reputation** (-100 до 100) - репутация на рынке
- **void_experience** (0 до 50) - опыт в зоне Void
- **negotiation_skill** (1 до 10) - навык переговоров
- **corporate_connections** (0 до 20) - корпоративные связи

#### Создание новых точек:
1. Откройте вкладку "Точки"
2. Нажмите "Добавить точку"
3. Настройте параметры:
   - **Имя** и **описание**
   - **Тип** (numeric/boolean/string)
   - **Категория** (story/skill/relationship/resource/custom)
   - **Диапазон значений** (min/max)
   - **Теги** для организации

### 5. **Типы последствий (Consequences)**

#### Экономические:
```json
{ "type": "gain_credits", "amount": 500 }
{ "type": "lose_credits", "amount": 200 }
```

#### Сюжетные точки:
```json
{ "type": "story_point_change", "pointId": "market_reputation", "change": 5 }
```

#### Активы:
```json
{ "type": "gain_talent", "talentData": { "name": "Элитный талант", "rank": "A" } }
```

#### Оборудование:
```json
{ "type": "gain_equipment", "equipmentId": "scanner_data" }
```

### 6. **Навигация между экранами**

#### Типы переходов:
```json
{ "type": "goto_screen", "screenId": "next_screen" }
{ "type": "end_scene" }
{ "type": "conditional_goto", "condition": {...} }
```

### 7. **Интеграция с игровыми механиками**

#### Психо-матрица:
- События влияют на фетиши, страхи, воспоминания
- Используйте RAG для генерации персонализированных реакций

#### Экономика:
- Изменения кредитов и репутации
- Влияние на цены и доступность

#### Активы:
- Получение и тренировка талантов
- Влияние на devotion и навыки

### 8. **Советы по созданию**

#### 🎯 Принципы дизайна:
1. **Всегда привязывайте к сюжетным точкам** - это основа системы
2. **Используйте вероятности** - для динамичности геймплея
3. **Создавайте ветвления** - множественные пути развития
4. **Балансируйте последствия** - не делайте события слишком сильными
5. **Тестируйте интеграцию** - проверяйте влияние на игру

#### 🔧 Технические советы:
- Используйте нормализованные данные
- Проверяйте типы значений
- Добавляйте теги для организации
- Сохраняйте изменения регулярно

### 9. **Отладка и тестирование**

#### Проверка ошибок:
- Откройте консоль браузера (F12)
- Ищите ошибки TypeScript
- Проверьте структуру данных

#### Тестирование событий:
- Используйте StoryPreview
- Проверяйте триггеры
- Тестируйте последствия

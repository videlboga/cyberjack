# Отчет об исправлении Game Page

## 📋 **Проблема найдена и исправлена**

**В `app/game/page.tsx` все еще использовались старые ссылки на `skills` вместо `fetishes`.**

## ✅ **Исправленные места**

### **1. Функция `getGroupedAttributes` (строка 434)**
```typescript
// БЫЛО:
const grouped: Record<string, any[]> = {
  attributes: [],
  states: [],
  skills: [],        // ❌ Старый код
  resources: []
}

// СТАЛО:
const grouped: Record<string, any[]> = {
  attributes: [],
  states: [],
  fetishes: [],      // ✅ Новый код
  resources: []
}
```

### **2. Функция `getEntitiesList` для случая 'system' (строка 370)**
```typescript
// БЫЛО:
if (config?.skills) {
  config.skills.filter((skill: any) => !skill.deleted).forEach((skill: any) => {
    systemList.push({ ...skill, type: 'skill', category: 'skills' })
  })
}

// СТАЛО:
if (config?.fetishes) {
  config.fetishes.filter((fetish: any) => !fetish.deleted).forEach((fetish: any) => {
    systemList.push({ ...fetish, type: 'fetish', category: 'fetishes' })
  })
}
```

### **3. Отображение иконки (строка 613)**
```typescript
// БЫЛО:
{category === 'skills' && <Star className="h-5 w-5" />}

// СТАЛО:
{category === 'fetishes' && <Star className="h-5 w-5" />}
```

## 🚀 Как использовать улучшенный редактор

### 1. **Сюжетные точки (Story Points)**

#### Типы точек и их назначение:

##### 🔢 **Число (Numeric)**
- **Что это**: Числовые значения с диапазоном
- **Примеры использования**:
  - `market_reputation` (0 до 100) - репутация на рынке
  - `negotiation_skill` (1 до 10) - навык переговоров
  - `void_experience` (0 до 50) - опыт в зоне Void
  - `corporate_connections` (0 до 20) - корпоративные связи
  - `credits` (0 до 10000) - деньги игрока
  - `energy` (0 до 100) - энергия персонажа

##### ✅ **Да/Нет (Boolean)**
- **Что это**: Логические флаги (истина/ложь)
- **Примеры использования**:
  - `has_implant` - наличие импланта
  - `is_corporate_member` - членство в корпорации
  - `void_access_granted` - доступ к зоне Void
  - `training_completed` - завершение тренировки
  - `quest_active` - активный квест
  - `relationship_established` - установленные отношения

##### 📝 **Текст (String)**
- **Что это**: Текстовые значения
- **Примеры использования**:
  - `current_location` - текущая локация
  - `active_npc_name` - имя активного NPC
  - `last_quest_id` - ID последнего квеста
  - `faction_alignment` - принадлежность к фракции
  - `special_status` - особый статус

#### Категории точек:

##### 💕 **Отношения (Relationship)**
- Дружба с фракциями
- Романтические связи
- Деловые партнерства
- Враждебность

##### ⚔️ **Навыки (Skill)**
- Боевые навыки
- Социальные навыки
- Технические навыки
- Торговые навыки

##### 💰 **Ресурсы (Resource)**
- Деньги
- Материалы
- Энергия
- Предметы

##### 📖 **Сюжет (Story)**
- Прогресс сюжета
- Открытые локации
- Выполненные квесты
- Сюжетные флаги

##### 🎯 **Другое (Custom)**
- Специальные параметры
- Временные флаги
- Экспериментальные механики

### 2. **Условия (Conditions)**

#### Как создавать условия:

1. **Перейдите на вкладку "Условия"**
2. **Нажмите "Добавить условие"**
3. **Заполните поля**:
   - **Название**: "Высокая репутация"
   - **Описание**: "Проверяет, что репутация на рынке выше 50"
   - **Сюжетная точка**: Выберите `market_reputation`
   - **Тип условия**: `greater` (больше)
   - **Значение**: `50`

#### Типы условий:

##### 🔗 **Равно (equals)**
- Проверяет точное совпадение
- Пример: `market_reputation = 100`

##### ➕ **Больше (greater)**
- Проверяет, что значение больше указанного
- Пример: `negotiation_skill > 5`

##### ➖ **Меньше (less)**
- Проверяет, что значение меньше указанного
- Пример: `void_experience < 10`

##### 📊 **Диапазон (range)**
- Проверяет, что значение в диапазоне
- Пример: `corporate_connections` от 5 до 15

##### 🔍 **Содержит (contains)**
- Для текстовых значений
- Пример: `current_location` содержит "Void"

#### Примеры условий:

```json
{
  "high_reputation": {
    "name": "Высокая репутация",
    "description": "Репутация на рынке выше 50",
    "storyPointId": "market_reputation",
    "type": "greater",
    "value": 50
  },
  "void_experienced": {
    "name": "Опыт в Void",
    "description": "Имеет опыт работы в зоне Void",
    "storyPointId": "void_experience",
    "type": "greater",
    "value": 10
  },
  "corporate_friend": {
    "name": "Друг корпораций",
    "description": "Корпоративные связи в диапазоне 10-20",
    "storyPointId": "corporate_connections",
    "type": "range",
    "value": 10,
    "secondValue": 20
  }
}
```

### 3. **Триггеры (Triggers)**

#### Как создавать триггеры:

1. **Перейдите на вкладку "Триггеры"**
2. **Нажмите "Добавить триггер"**
3. **Заполните поля**:
   - **Название**: "Автоматический аукцион"
   - **Описание**: "Запускает аукцион при высокой репутации"
   - **Активен**: Включите чекбокс

#### Примеры триггеров:

```json
{
  "auto_auction": {
    "name": "Автоматический аукцион",
    "description": "Запускает корпоративный аукцион при высокой репутации",
    "conditionIds": ["high_reputation"],
    "actions": [
      {
        "type": "showDialog",
        "target": "corporate_auction_invitation",
        "value": "Вас приглашают на корпоративный аукцион!"
      }
    ],
    "isActive": true
  },
  "void_mission": {
    "name": "Миссия в Void",
    "description": "Предлагает миссию при достаточном опыте",
    "conditionIds": ["void_experienced"],
    "actions": [
      {
        "type": "unlockScene",
        "target": "void_rescue_mission",
        "value": true
      }
    ],
    "isActive": true
  }
}
```

### 4. **Практические примеры**

#### Создание системы репутации:

1. **Создайте сюжетную точку**:
   - Тип: `numeric`
   - Категория: `story`
   - Название: "Репутация на рынке"
   - Диапазон: 0-100
   - Теги: `market`, `reputation`, `trading`

2. **Создайте условия**:
   - "Низкая репутация" (0-30)
   - "Средняя репутация" (31-70)
   - "Высокая репутация" (71-100)

3. **Создайте триггеры**:
   - При низкой репутации → доступ к чёрному рынку
   - При высокой репутации → корпоративные аукционы

#### Создание системы навыков:

1. **Создайте сюжетные точки**:
   - `negotiation_skill` (1-10)
   - `void_experience` (0-50)
   - `corporate_connections` (0-20)

2. **Создайте условия**:
   - "Мастер переговоров" (навык > 8)
   - "Опытный исследователь" (опыт > 30)
   - "Корпоративный инсайдер" (связи > 15)

3. **Создайте триггеры**:
   - Мастер переговоров → скидки на рынке
   - Опытный исследователь → доступ к редким локациям
   - Корпоративный инсайдер → эксклюзивные контракты

### 5. **Интеграция с игровыми механиками**

#### Связь с событиями:
- Условия определяют, какие события доступны
- Триггеры автоматически запускают события
- Сюжетные точки отслеживают прогресс

#### Связь с экономикой:
- Репутация влияет на цены
- Навыки влияют на эффективность
- Ресурсы ограничивают возможности

#### Связь с сюжетом:

- Выборы влияют на развитие
- Последствия накапливаются

# 🎯 Реализация лучших практик для плавающих панелей

## 📋 Обзор выполненной работы

### ✅ Что было реализовано:

1. **Переиспользуемый хук `useDraggable`** - централизованная логика drag & drop
2. **Менеджер z-index `useZIndexManager`** - управление слоями панелей
3. **Хук сохранения позиций `usePanelPosition`** - localStorage для позиций
4. **Базовый компонент `FloatingPanel`** - универсальная обертка для панелей
5. **Рефакторинг существующих панелей** - ActionToolPanel и CharacterChat

## 🏗️ Архитектура решения

### 1. **Хук useDraggable** (`hooks/useDraggable.ts`)

```typescript
export function useDraggable(
  initialPosition: Position,
  onPositionChange?: (position: Position) => void,
  constraints?: DragConstraints,
  dragHandleSelector: string = '[data-draggable="true"]'
)
```

**Особенности:**
- ✅ Поддержка ограничений (границы экрана)
- ✅ Touch события для мобильных устройств
- ✅ Предотвращение выделения текста
- ✅ Настраиваемый селектор для области перетаскивания
- ✅ Оптимизированные useCallback

### 2. **Менеджер z-index** (`hooks/useZIndexManager.ts`)

```typescript
class ZIndexManager {
  private static instance: ZIndexManager;
  private baseZIndex = 1000;
  private activePanels = new Map<string, number>();
}
```

**Функциональность:**
- ✅ Singleton паттерн для глобального управления
- ✅ Автоматическое выведение на передний план при клике
- ✅ Управление жизненным циклом панелей
- ✅ Динамическое перераспределение z-index

### 3. **Сохранение позиций** (`hooks/usePanelPosition.ts`)

```typescript
export function usePanelPosition(
  panelId: string, 
  defaultPosition: PanelPosition,
  defaultLayout?: Partial<PanelLayout>
)
```

**Возможности:**
- ✅ Автоматическое сохранение в localStorage
- ✅ Восстановление позиций при перезагрузке
- ✅ Поддержка минимизации/максимизации
- ✅ Сброс к позиции по умолчанию

### 4. **Базовый компонент FloatingPanel** (`components/ui/FloatingPanel.tsx`)

```typescript
export function FloatingPanel({
  children,
  title,
  panelId,
  onClose,
  defaultPosition = { x: 100, y: 100 },
  // ... другие props
})
```

**Функции:**
- ✅ Drag & drop из коробки
- ✅ Управление z-index
- ✅ Сохранение позиций
- ✅ Кнопки управления (свернуть/развернуть/закрыть)
- ✅ Адаптивные ограничения
- ✅ Анимации и переходы

## 🔄 Рефакторинг существующих компонентов

### ActionToolPanel
**Было:**
```typescript
// Дублированная логика drag & drop
const [isDragging, setIsDragging] = useState(false);
const [dragOffset, setDragOffset] = useState({ x: 0, y: 0 });
const handleMouseDown = (e: React.MouseEvent) => { /* ... */ };
// ... много кода для перетаскивания
```

**Стало:**
```typescript
<FloatingPanel
  panelId="action-tool-panel"
  title="🎮 Действия и инструменты"
  onClose={onClose}
  defaultPosition={{ x: 100, y: 100 }}
  minWidth={400}
  minHeight={500}
>
  {/* Содержимое панели */}
</FloatingPanel>
```

## Основные причины падения тестов

### 1. Проблемы с моками
- Моки не могут найти модули `@/lib/config-loader` и `@/lib/field-configs`
- Проблемы с разрешением путей в Jest

### 2. Проблемы с поиском элементов
- Тесты не могут найти элементы по `getByLabelText` и `getByDisplayValue`
- Проблемы с рендерингом компонентов в тестовой среде

### 3. Проблемы с асинхронностью
- Элементы могут не успеть отрендериться к моменту поиска

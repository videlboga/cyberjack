# Отчет о синхронизации конфигураций Dev ↔ Prod

## 🔍 **Анализ проблемы**

### **Исходная ситуация:**
- ❌ Dev версия использовала `*-config.json` файлы (только настройки)
- ❌ Prod версия использовала основные `*.json` файлы (реальные данные)
- ❌ Отсутствие синхронизации между версиями
- ❌ Неполное отображение сущностей в dev версии

### **Обнаруженные различия:**
1. **actions-config.json** vs **actions.json**
   - config: только настройки категорий
   - json: полные данные действий с эффектами, рисками, памятью

2. **market-config.json** vs **market.json**
   - config: настройки рынка, условия, риски
   - json: реальные таланты, void rescues, корпоративные контракты

3. **contracts-config.json** vs **contracts.json**
   - config: настройки контрактов
   - json: доступные контракты с требованиями и наградами

4. **events-config.json** vs **events.json**
   - config: настройки событий
   - json: аномалии, кризисы, возможности

## ✅ **Выполненные исправления**

### **1. Унификация источников данных**
- ✅ Dev версия теперь использует те же `*.json` файлы, что и prod
- ✅ Удалены зависимости от `*-config.json` файлов
- ✅ Обе версии работают с единым источником истины

### **2. Обновление логики обработки данных**

- ✅ Обновлены начальные конфигурации

### **3. Создание утилит синхронизации**

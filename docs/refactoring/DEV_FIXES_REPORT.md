## ✅ **Выполненные исправления**

### **1. Исправление проблемы с атрибутами**

**Обновлена функция `getEntitiesList()` в `app/game/page.tsx`:**
```typescript
case 'system':
  // Обрабатываем структуру system-definitions.json
  const systemList: any[] = []
  if (config?.attributes) systemList.push(...config.attributes)
  if (config?.states) systemList.push(...config.states)
  if (config?.skills) systemList.push(...config.skills)
  if (config?.resources) systemList.push(...config.resources)
  return systemList
```

**Добавлена схема для типа `system` в `configHelpers.ts`:**
```typescript
system: {
  type: 'system',
  fields: [
    { name: 'name', type: 'text', label: 'Название', required: true },
    { name: 'description', type: 'textarea', label: 'Описание', required: true },
    { name: 'type', type: 'select', label: 'Тип', required: true, options: ['attribute', 'skill', 'state', 'resource'] },
    { name: 'minValue', type: 'number', label: 'Минимальное значение', required: false },
    { name: 'maxValue', type: 'number', label: 'Максимальное значение', required: false },
    { name: 'defaultValue', type: 'number', label: 'Значение по умолчанию', required: false }
  ],
  defaultValues: {
    id: '',
    name: '',
    description: '',
    type: 'attribute',
    minValue: 0,
    maxValue: 100,
    defaultValue: 50
  }
}
```

### **3. Создание улучшенного модального окна**

**Создан новый компонент `EnhancedEditModal.tsx`:**
- ✅ Удобные поля ввода (текст, текстовая область, числа, селекты)
- ✅ Слайдеры для числовых значений
- ✅ Переключатели для булевых значений
- ✅ Валидация обязательных полей
- ✅ Разделение на основные и дополнительные поля
- ✅ Поддержка всех типов данных

**Типы полей:**
- **text**: Текстовые поля с плейсхолдерами
- **textarea**: Многострочные текстовые поля
- **number**: Числовые поля с ограничениями
- **select**: Выпадающие списки с опциями
- **slider**: Слайдеры для числовых значений
- **switch**: Переключатели для булевых значений
- **object**: JSON поля для объектов
- **array**: JSON поля для массивов

**Конфигурации для разных типов сущностей:**
- **actions**: Название, описание, стоимость, риск, эффекты
- **contracts**: Название, описание, клиент, награда, срок, сложность
- **events**: Название, описание, вероятность, длительность, эффекты
- **equipment**: Название, описание, тип, слот, съемное, эффекты
- **market**: Название, описание, цена, риск, специализация
- **system**: Название, описание, категория, мин/макс значения
- **scenes**: ID, название, описание, тип, персонажи, выборы

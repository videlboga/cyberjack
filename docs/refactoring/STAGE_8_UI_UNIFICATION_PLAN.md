# Этап 8: Минимальная унификация UI компонентов - ПЛАН

**Дата создания:** 26 августа 2025  
**Статус:** В РАЗРАБОТКЕ  

## 🎯 Цель этапа 8

Создать минимальную унификацию UI компонентов, объединив дублирующиеся компоненты и создав единую архитектуру для подготовки к будущей переработке UI.

## 📋 Анализ текущего состояния

### Существующие UI компоненты (~60 файлов)

**Кастомные игровые компоненты:**
- `AttributeSelector.tsx` (8.9KB) - выбор атрибутов
- `ConditionBuilder.tsx` (12KB) - построитель условий
- `EntitySelector.tsx` (2.1KB) - выбор сущностей
- `OperatorSelector.tsx` (1.7KB) - выбор операторов
- `ValueInput.tsx` (4.5KB) - ввод значений
- `character-stats-panel.tsx` (14KB) - панель характеристик
- `stat-notification.tsx` (3KB) - уведомления статистики
- `FloatingPanel.tsx` (5.5KB) - плавающие панели

**Стандартные shadcn/ui компоненты:**
- `button.tsx`, `card.tsx`, `input.tsx`, `select.tsx` и др.

### Выявленные проблемы

1. **Разрозненность кастомных компонентов** - нет единой структуры
2. **Дублирование логики** - похожие компоненты в разных местах
3. **Отсутствие единых типов** - разные интерфейсы для похожих компонентов
4. **Сложность поддержки** - много отдельных файлов

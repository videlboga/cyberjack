# Универсальный сюжетный редактор - Руководство

## Обзор

Универсальный сюжетный редактор - это мощный инструмент для создания и управления всеми типами событий в игре CyberJack. Он заменяет отдельные системы для разных типов событий (Активности, Заказы, Аномалии) единой универсальной системой.

## Основные возможности

### 1. Визуальный редактор сюжетов
- **Drag & Drop интерфейс** с использованием React Flow
- **Различные типы узлов**: Сцены, Экраны, Выборы, Триггеры
- **Цветовая кодировка** для разных типов событий
- **Интерактивные соединения** между элементами

### 2. Шаблоны событий
- **Готовые шаблоны** для всех типов событий
- **Быстрое создание** новых сюжетов
- **Кастомизация** существующих шаблонов
- **Поиск и фильтрация** по типам

### 3. Интеграция с игровыми системами
- **Связывание сюжетов** с игровыми событиями
- **Автоматические триггеры** на основе условий
- **Управление вероятностями** и эффектами
- **Синхронизация** с игровыми данными

## Типы событий

### Рынок (Market)
- **Описание**: Торговля талантами и ресурсами
- **Иконка**: 📦 Package
- **Цвет**: Синий
- **Примеры**: Talent Exchange, торговые сделки

### Аукцион (Auction)
- **Описание**: Конкурентные торги за редкие активы
- **Иконка**: 🎯 Target
- **Цвет**: Фиолетовый
- **Примеры**: Корпоративные аукционы, продажа элитных талантов

### Аномалии (Anomaly)
- **Описание**: Странные события в Void Border
- **Иконка**: ⚠️ AlertTriangle
- **Цвет**: Красный
- **Примеры**: Временные искажения, редкие находки

### Контракты (Contract)
- **Описание**: Долгосрочные соглашения с корпорациями
- **Иконка**: 🏢 Building
- **Цвет**: Зеленый
- **Примеры**: Поставка талантов, корпоративные миссии

### Спасение в Void (Void Rescue)
- **Описание**: Опасные миссии по спасению
- **Иконка**: ⚡ Zap
- **Цвет**: Желтый
- **Примеры**: Спасательные операции, поиск потерянных активов

### Корпоративные (Corporate)
- **Описание**: Взаимодействие с корпорациями
- **Иконка**: 👥 Users
- **Цвет**: Индиго
- **Примеры**: Корпоративные встречи, переговоры

### Тренировки (Training)
- **Описание**: Развитие навыков активов
- **Иконка**: 🎮 Gamepad2
- **Цвет**: Оранжевый
- **Примеры**: Обучение, коучинг, нейроулучшения

### Терапия (Therapy)
- **Описание**: Психологическая работа с активами
- **Иконка**: ⭐ Star
- **Цвет**: Розовый
- **Примеры**: Психотерапия, реабилитация, кризисное вмешательство

## Структура сюжета

### Сцена (Scene)
- **Основной контейнер** для всего сюжета
- **Метаданные**: название, описание, тип, теги
- **Триггеры**: условия активации
- **Экраны**: последовательность игровых моментов

### Экраны (Screens)
- **Отдельные моменты** в сюжете
- **Фон и музыка**: атмосфера сцены
- **Выборы**: варианты действий игрока
- **Автопрогресс**: автоматический переход

### Выборы (Choices)
- **Варианты действий** для игрока
- **Последствия**: эффекты от выбора
- **Навигация**: переход к следующему экрану
- **Условия**: ограничения для выбора

### Триггеры (Triggers)
- **Условия активации** сюжета
- **Типы**: сюжетные точки, состояние игры, время
- **Вероятность**: шанс срабатывания
- **Приоритет**: порядок проверки

## Создание нового сюжета

### 1. Выбор шаблона
1. Перейдите на вкладку "Шаблоны"
2. Найдите подходящий шаблон по типу или поиску
3. Нажмите "Использовать" для применения шаблона

### 2. Редактирование в универсальном редакторе
1. Перейдите на вкладку "Универсальный редактор"
2. Выберите узел для редактирования
3. Измените свойства в панели справа
4. Добавьте новые экраны и выборы

### 3. Настройка триггеров
1. Добавьте триггеры для активации сюжета
2. Настройте условия и вероятности
3. Укажите приоритеты срабатывания

### 4. Интеграция с игрой
1. Перейдите на вкладку "Интеграция"
2. Свяжите сюжет с игровым событием
3. Настройте эффекты и последствия

## Лучшие практики

### 1. Структура сюжета
- **Начинайте с простых сюжетов** из 2-3 экранов
- **Используйте логическую последовательность** экранов
- **Добавляйте разнообразие** в выборы игрока
- **Тестируйте навигацию** между экранами

### 2. Триггеры и условия
- **Используйте реалистичные вероятности** (5-30%)
- **Комбинируйте разные типы триггеров**
- **Избегайте конфликтующих условий**
- **Тестируйте срабатывание** триггеров

### 3. Интеграция
- **Связывайте сюжеты** с соответствующими игровыми событиями
- **Балансируйте награды** и последствия
- **Учитывайте игровой прогресс** в условиях
- **Синхронизируйте** с существующими системами

### 4. Производительность
- **Ограничивайте количество** экранов в сюжете (до 10)
- **Оптимизируйте** изображения и аудио
- **Кэшируйте** часто используемые ресурсы
- **Мониторьте** время загрузки

## Примеры использования

### Создание аукциона талантов
1. Выберите шаблон "Корпоративный аукцион"
2. Настройте триггеры: репутация рынка >= 50
3. Добавьте экраны: вход, торги, результат
4. Свяжите с игровым событием "auction"

### Создание аномалии в Void
1. Выберите шаблон "Аномалия в Void"
2. Настройте триггеры: опыт в Void >= 1
3. Добавьте экраны: обнаружение, исследование, результат
4. Свяжите с игровым событием "anomaly"

### Создание корпоративного контракта
1. Выберите шаблон "Корпоративный контракт"
2. Настройте триггеры: корпоративные связи >= 5
3. Добавьте экраны: встреча, переговоры, подписание
4. Свяжите с игровым событием "contract"

## Миграция с старых систем

### Из раздела "Активности"
- Создайте сюжеты типа "training" или "therapy"
- Перенесите логику действий в выборы
- Настройте триггеры на основе состояний активов

### Из раздела "Заказы"
- Создайте сюжеты типа "contract"
- Перенесите условия контрактов в триггеры
- Настройте награды и последствия

### Из раздела "Аномалии"
- Создайте сюжеты типа "anomaly"
- Перенесите эффекты в последствия выборов
- Настройте вероятности срабатывания

## Отладка и тестирование

### Проверка структуры
- Убедитесь, что все экраны связаны
- Проверьте навигацию между экранами
- Тестируйте все варианты выборов

### Проверка триггеров
- Симулируйте условия активации
- Проверьте вероятности срабатывания
- Тестируйте конфликты между триггерами

### Проверка интеграции
- Убедитесь в правильной связи с игровыми событиями
- Проверьте эффекты и последствия
- Тестируйте синхронизацию данных

## Заключение

Универсальный сюжетный редактор предоставляет мощные инструменты для создания богатого игрового контента. Используйте шаблоны для быстрого старта, экспериментируйте с различными типами событий и создавайте уникальные игровые переживания для игроков.

Для получения дополнительной помощи обратитесь к документации по API или свяжитесь с командой разработки.

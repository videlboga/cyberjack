# Отчет о новой двухэтапной системе ИИ

## Проблема
Предыдущая система использовала один этап генерации, что приводило к смешиванию анализа контекста и генерации ответа персонажа.

## Решение: Двухэтапная система

### Этап 1: Анализ контекста (Gemini 2.5 Flash Lite)
**Цель**: Анализировать сообщение пользователя и возвращать структурированный JSON с влиянием на персонажа.

**Входные данные**:
- Сообщение пользователя
- Контекст персонажа (имя, роль, личность, состояние)
- Характеристики персонажа
- Активные фетиши
- Текущие состояния

**Выходные данные** (JSON):
```json
{
  "emotionalContent": {
    "threat": 0.0,
    "pleasure": 0.0,
    "pain": 0.0,
    "fear": 0.0,
    "arousal": 0.0
  },
  "statChanges": {
    "mood": 5,
    "anxiety": -2
  },
  "fetishTriggers": ["bondage", "submission"],
  "commands": {
    "poseChange": "kneeling",
    "action": "submit"
  }
}
```

### Этап 2: Генерация ответа персонажа (LLaMA 3.1 70B)
**Цель**: Генерировать естественный ответ персонажа на основе анализа и его личности.

**Входные данные**:
- Базовый промт персонажа
- Характеристики в формате интерпретаций
- События из анализа (изменения характеристик, активированные фетиши, приказы)
- Сообщение пользователя

**Выходные данные**: Естественный ответ персонажа

## Техническая реализация

### Обновленный `MessageAnalysisService`

```typescript
async analyzeMessage(
  message: string,
  characterContext: LLMPrompt,
  currentStates: { [key: string]: number }
): Promise<MessageAnalysis> {
  // Этап 1: Анализ контекста через Gemini
  const analysisPrompt = this.buildContextAnalysisPrompt(message, characterContext, currentStates);
  const analysisResponse = await this.callOpenRouterAPI(analysisPrompt, 'google/gemini-2.5-flash-lite');
  const analysis = this.parseAnalysisResponse(analysisResponse);
  
  // Этап 2: Генерация ответа персонажа через LLaMA
  const characterResponsePrompt = this.buildCharacterResponsePrompt(message, characterContext, analysis);
  const characterResponse = await this.callOpenRouterAPI(characterResponsePrompt, 'meta-llama/llama-3.1-70b-instruct');
  
  // Объединяем результаты
  return {
    ...analysis,
    response: characterResponse
  };
}
```

### Новые методы

1. **`buildContextAnalysisPrompt()`** - создает промт для анализа контекста
2. **`buildCharacterResponsePrompt()`** - создает промт для генерации ответа персонажа
3. **`formatAnalysis()`** - форматирует анализ в нужную структуру
4. **Обновленный `callOpenRouterAPI()`** - поддерживает разные модели

## Преимущества новой системы

### ✅ Разделение ответственности
- **Gemini**: Анализ и структурирование данных
- **LLaMA**: Генерация естественного текста

### ✅ Лучшее качество анализа
- Специализированный промт для анализа контекста
- Структурированный JSON-ответ
- Точные изменения характеристик и состояний

### ✅ Более естественные ответы
- Персонализированные промты для каждого персонажа
- Учет событий из анализа
- Интеграция характеристик и фетишей

### ✅ Масштабируемость
- Легко добавлять новые модели для каждого этапа
- Возможность настройки промтов под конкретные задачи
- Раздельная оптимизация каждого этапа

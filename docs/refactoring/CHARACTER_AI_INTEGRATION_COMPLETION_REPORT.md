## 🎮 Как использовать

1. **Включение AI режима**: Нажмите кнопку "Личная работа" в верхней панели
2. **Панель действий**: Откроется автоматически, можно перетаскивать
3. **Быстрые действия**: Нажмите кнопку "⚡ Быстрые действия" в нижней панели
4. **Переключение**: Используйте кнопки в нижней панели управления
5. **Закрытие**: Нажмите ✕ в правом верхнем углу панели или кнопку "Личная работа"

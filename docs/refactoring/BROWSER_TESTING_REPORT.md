## 🔧 Технические исправления

### 🚨 Критическая ошибка исправлена:
**Проблема:** `Maximum call stack size exceeded` в хуке `useToast`
**Причина:** Бесконечная рекурсия в `useEffect` с зависимостью `[state]`
**Решение:** Изменена зависимость на `[]` в файлах:
- `hooks/use-toast.ts`
- `components/ui/use-toast.ts`

```typescript
// БЫЛО:
React.useEffect(() => {
  listeners.push(setState)
  return () => {
    const index = listeners.indexOf(setState)
    if (index > -1) {
      listeners.splice(index, 1)
    }
  }
}, [state]) // ❌ Бесконечная рекурсия

// СТАЛО:
React.useEffect(() => {
  listeners.push(setState)
  return () => {
    const index = listeners.indexOf(setState)
    if (index > -1) {
      listeners.splice(index, 1)
    }
  }
}, []) // ✅ Исправлено
```

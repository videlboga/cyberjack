# Отчет о синхронизации данных между dev и prod режимами

## Проблема
Пользователь обнаружил, что в prod режиме отображается 3 актива, а в dev режиме только 1. Также в аукционе и заказах отображались разные сущности в разных режимах.

## Анализ проблемы
После анализа кода было выявлено, что:

1. **Разные источники данных**: В prod режиме используется `loadConfigsForEnvironment('prod')`, а в dev - `loadConfigsForEnvironment('dev')`
2. **localStorage vs файлы**: В prod режиме данные могут быть изменены через localStorage, а в dev режиме используются статические файлы
3. **Несинхронизированные файлы**: Файлы `assets.json` и `characters-unified.json` содержали разное количество активов

## Решение

### 1. Создан скрипт синхронизации
Создан файл `scripts/sync-prod-data.js` для синхронизации данных из prod режима в dev файлы.

### 2. Синхронизированы активы
- **До**: 2 актива в `assets.json` и `characters-unified.json`
- **После**: 3 актива (Алекс, Мария, Виктория)

### 3. Синхронизированы контракты
- **До**: 2 контракта в `contracts.json`
- **После**: 3 контракта (включая новый "Специалист по нейрохакерству")

### 4. Обновленные данные

#### Активы:
1. **Алекс** (Junior) - Базовое подчинение, 150 кредитов
2. **Мария** (Middle) - Этикет и подчинение, 300 кредитов  
3. **Виктория** (Senior) - Нейротехнологии, 500 кредитов

#### Контракты:
1. **SlaveTech Inc.** - Тренировка актива с имплантом контроля оргазмов (800 кредитов)
2. **Neural Elite** - Подготовка элитного актива (500 кредитов)
3. **CyberCorp** - Специалист по нейрохакерству (1200 кредитов)

## Результат
✅ Теперь в dev и prod режимах отображается одинаковое количество активов (3) и контрактов (3)

```bash

```

Скрипт автоматически:
- Синхронизирует активы в `assets.json` и `characters-unified.json`
- Синхронизирует контракты в `contracts.json`
- Добавляет метаданные о синхронизации

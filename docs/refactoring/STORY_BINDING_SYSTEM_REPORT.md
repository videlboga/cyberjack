## 📊 Поддерживаемые типы условий

### 1. Условия на активы (Asset)
- ✅ `any_asset_price` - максимальная цена среди всех активов
- ✅ `owned_assets_count` - количество принадлежащих активов
- ✅ `total_assets_value` - общая стоимость активов
- ✅ `strength`, `intelligence` - атрибуты активов
- ✅ `price`, `rank` - метаданные активов

### 2. Условия на игрока (Player)
- ✅ `balance` - баланс кредитов
- ✅ `owned_assets_count` - количество активов
- ✅ `equipment_count` - количество оборудования

### 3. Условия на игровое состояние (Game State)
- ✅ `day` - текущий день игры
- ✅ `reputation` - репутация игрока
- ✅ `void_experience` - опыт в Void

## 🔧 Поддерживаемые операторы

- ✅ `==` равно
- ✅ `!=` не равно
- ✅ `>` больше
- ✅ `<` меньше
- ✅ `>=` больше или равно
- ✅ `<=` меньше или равно

## 🎮 Примеры использования

### Аукцион
```typescript
// Базовый шанс (30%)
const basicAuction = StoryBindingUtils.createAuctionBaseBinding('market_intro')

// Привязка с условием на активы (60%)
const highValueAuction = StoryBindingUtils.createAssetConditionBinding(
  'auction',
  'corporate_auction',
  'any_asset_price',
  '>',
  1000,
  60
)

// Привязка с условием на игрока (80%)
const eliteAuction = StoryBindingUtils.createPlayerConditionBinding(
  'auction',
  'elite_auction',
  'balance',
  '>',
  5000,
  80
)
```

### Аномалии
```typescript
// Базовая аномалия (20%)
const basicAnomaly = StoryBindingUtils.createAnomalyBaseBinding('void_anomaly')

// Аномалия для опытных (50%)
const experiencedAnomaly = StoryBindingUtils.createBinding(
  'anomaly',
  'void_anomaly',
  [
    StoryBindingUtils.createCondition(
      'game_state',
      'void_experience',
      '>',
      5,
      'Опыт в Void более 5 операций'
    )
  ],
  50,
  2,
  false
)
```
